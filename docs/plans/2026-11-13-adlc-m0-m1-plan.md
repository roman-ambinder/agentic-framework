# ADLC — Build Plan for M0 and M1

Design: `docs/design/2026-11-13-adlc-framework-design.md`
Stack: Go core · Protobuf/gRPC contracts · MCP tools · Docker sandbox · SQLite (`modernc.org/sqlite`) · OpenTelemetry · Anthropic + OpenAI adapters.

Each task is small enough for one PR and ends with a test proving it works. Order matters: each task builds only on earlier ones.

---

## M0 — Contracts and skeleton

Goal: `adlc run examples/hello.yaml` runs an agent that calls a fake model, uses one tool, writes an event log, and prints a trace. No real model, no Docker yet.

| # | Task | Done when |
|---|------|-----------|
| 0.1 | Repo bootstrap: `go.mod`, `cmd/adlc` (cobra or stdlib flags), Makefile, golangci-lint, CI running `go test ./...` | CI is green on an empty `adlc version` |
| 0.2 | `contracts/proto/adlc/v1/events.proto`: `Event`, event types, `Cost`, `StopReason`; `buf` codegen into `gen/go` | Generated code compiles; a schema-compat check runs in CI |
| 0.3 | `internal/eventlog`: append-only SQLite store, `Append`, `Read(runID)`, `Fold(runID) → RunState` | Unit tests: append/read ordering, fold is deterministic, safe for concurrent appends |
| 0.4 | `ModelAdapter` interface + normalized types (`Message`, `ToolCall`, `ToolResult`, `ModelEvent` with opaque provider blobs) + a **scripted fake adapter** | Fake replays a scripted conversation in tests |
| 0.5 | `internal/harness`: the loop with step/token/time/$ budgets, retries with backoff, stop reasons, `pre_tool`/`post_tool` hooks, checkpoints written to the event log | Table tests per stop reason, using the fake adapter |
| 0.6 | `PolicyClient` interface + local static allow/deny implementation, using tool **risk classes** | A tool call that is denied ends the run with `denied`; an allowed one runs |
| 0.7 | `internal/toolrouter`: MCP client (stdio), tool namespacing, risk class from config, output cap | Talks to a test MCP server; oversized output gets truncated and the full output is logged |
| 0.8 | `tools/fs`: first built-in MCP server in Go (read/list/write within a root dir) | Path-escape attempts (`../`) are rejected in tests |
| 0.9 | Agent definition schema (`agent.yaml`: model, prompt, tools, budgets, policy) + loader + validation | Bad configs fail with clear errors |
| 0.10 | Observability v0: event log → OTel spans (stdout exporter) + `adlc trace <run>` | Running hello.yaml prints a span tree with costs |
| 0.11 | **Cross-language check:** `contracts/proto/adlc/v1/plugin.proto` (`Hook` service), `internal/plugin` launcher, and one **Python** hook plugin in `examples/plugins/` | Integration test: the Python hook blocks a tool call |

**M0 exit:** hello agent runs end to end on the fake model; the log can be folded back to state; one non-Go plugin works.

## M1 — One agent fixes one issue

Goal: a coder agent, running in Docker against a small Go fixture repo, fixes a seeded bug so that hidden tests pass, and produces a diff. It must stay within budget, be fully traced, and be scored by an eval suite.

| # | Task | Done when |
|---|------|-----------|
| 1.1 | **Anthropic adapter** (`adapters/models/anthropic`): streaming, tool calls, refusal handling, cache control, `CountTokens`, thinking blobs passed back unchanged (see design §8) | Recorded-response tests + one live smoke test behind a `-tags live` build flag |
| 1.2 | **OpenAI adapter** (`adapters/models/openai`): same contract, configurable base URL | Same test suite as 1.1 runs against both adapters (shared contract tests) |
| 1.3 | Model router: pick a model per agent role / step kind, falling back to the other provider on outage | Fallback test using a failing fake |
| 1.4 | `internal/sandbox` + `docker` backend: create/exec/destroy, CPU/memory limits, **network off by default**, repo mounted as a working copy | Integration test: `go test` runs inside the container; outbound network fails |
| 1.5 | `tools/shell`, `tools/git`, `tools/search`: MCP servers that run **inside the sandbox** | The agent can run `go test ./...` and `git diff` only inside the container |
| 1.6 | Context manager v1: per-section token budgets, compaction of old tool output, stable prefix kept for caching | Long run stays under the context limit; cache hits visible in cost events |
| 1.7 | Resume: restart a crashed run from its last checkpoint | Kill the process mid-run, then `adlc resume <run>` completes it |
| 1.8 | Fixture suite: a small Go repo + about 10 seeded bugs, each with an issue text and hidden tests | `adlc eval` reports pass@1, cost and steps per task |
| 1.9 | Graders: outcome (hidden tests pass, `go vet` clean, diff applies) + trajectory (steps, wasted calls, policy violations) | Report shows both kinds of score; JSON output for CI |
| 1.10 | `agents/sdlc/coder.yaml` + its prompt | The agent passes a threshold you choose on the fixture suite |
| 1.11 | Cost report: per run / model / task, from cost events | `adlc cost` matches the sum of the events |

**M1 exit:** `adlc eval suites/go-bugs` runs all fixtures with both providers and prints a comparison of success rate, cost and steps.

---

## Testing approach
- **Unit:** harness, eventlog, policy, context manager, all using the fake adapter (no network).
- **Contract tests:** one suite every `ModelAdapter` must pass; the same idea for `Sandbox` backends.
- **Integration:** Docker sandbox + MCP servers; marked so they can be skipped where Docker is unavailable.
- **Live:** real API calls only under `-tags live`, never in default CI, so tests cost nothing by default.

## Not in M0/M1 (deliberately)
Orchestrator/DAG, approvals queue, registry and promotion, memory across runs, generated SDKs, web UI. These come in M2–M4 per the design.
