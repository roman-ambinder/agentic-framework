# 0.8 — fs MCP server

Size: M · Depends on: 0.7.2 · Branch: `task/0.8-tools-fs` · PR title: `0.8: fs MCP server and adlc tool fs`

## Goal

Package `internal/tools/fs` is an MCP server with three tools — `read_file`,
`list_dir`, `write_file` — that can only touch files under one root
directory. `adlc tool fs --root DIR` serves it over stdio, so an agent config
can start it with `command: ["adlc", "tool", "fs", "--root", "."]`.

  `AddTool` builds the input schema from the `In` struct (field `json` tags; a `jsonschema:"..."` tag becomes the description). Fields without `omitempty` are required. ## Design

```go
package fs // import "github.com/roman-ambinder/agentic-framework/internal/tools/fs"

// Options limit what the tools do. Zero values mean the defaults below.
type Options struct {
	MaxReadBytes  int64 // default 256 KiB
	MaxWriteBytes int64 // default 1 MiB
	MaxEntries    int   // default 1000
}

// NewServer returns an MCP server named "fs" whose tools work under root.
// The caller keeps ownership of root and closes it.
func NewServer(root *os.Root, opts Options) *mcp.Server
```

Server identity: `&mcp.Implementation{Name: "fs", Version: buildinfo.Get().Version}`.

### Tools (exact names, inputs, outputs)

Paths are always relative to the root and use `/`. Every handler starts with
the same helper:

```go
// cleanPath returns the cleaned path or an error "<tool> <p>: path escapes the root".
func cleanPath(tool, p string) (string, error) {
	if p == "" {
		p = "."
	}
	c := path.Clean(p)
	if !fs.ValidPath(c) { // rejects absolute paths and anything starting with ".."
		return "", fmt.Errorf("%s %s: path escapes the root", tool, p)
	}
	return c, nil
}
```

`os.Root` then catches the remaining escapes (symlinks pointing outside), with
errors containing `path escapes from parent`. Both texts contain `escapes`.

**`read_file`** — description: `Read a UTF-8 text file under the workspace root.`
```go
type readIn struct {
	Path string `json:"path" jsonschema:"file path relative to the workspace root"`
}
type readOut struct {
	Content   string `json:"content"`
	Size      int64  `json:"size"`      // full file size in bytes
	Truncated bool   `json:"truncated"` // true if only MaxReadBytes were returned
}
```
Algorithm:
1. `info, err := root.Stat(p)`; error → return `nil, readOut{}, fmt.Errorf("read_file %s: %w", p, err)`.
2. If `info.IsDir()` → error `read_file %s: is a directory`.
3. Open with `root.Open(p)`, read at most `MaxReadBytes` bytes with `io.ReadAll(io.LimitReader(f, max))`.
4. If `!utf8.Valid(data)` → error `read_file %s: not a UTF-8 text file`.
   (If the cut at `MaxReadBytes` split a character, first drop up to 3
   trailing bytes until valid; only then decide it is binary.)
5. Return `nil, readOut{Content: string(data), Size: info.Size(), Truncated: info.Size() > max}, nil`.

**`list_dir`** — description: `List the entries of a directory under the workspace root.`
```go
type listIn struct {
	Path string `json:"path,omitempty" jsonschema:"directory relative to the workspace root; default ."`
}
type entry struct {
	Name string `json:"name"`
	Type string `json:"type"` // "file", "dir", "symlink" or "other"
	Size int64  `json:"size"` // 0 for anything but files
}
type listOut struct {
	Entries   []entry `json:"entries"`
	Truncated bool    `json:"truncated"`
}
```
Algorithm: `fs.ReadDir(root.FS(), p)` (already sorted by name). For each
`DirEntry`: type from `d.Type()` (`IsDir` → dir, `ModeSymlink` → symlink,
regular → file, else other); size from `d.Info()` for files. Stop after
`MaxEntries` and set `Truncated`. Errors → `list_dir %s: %w`. Return an empty
non-nil `Entries` slice for an empty directory (JSON `[]`, not `null`).

**`write_file`** — description: `Create or overwrite a UTF-8 text file under the workspace root. Parent directories are created.`
```go
type writeIn struct {
	Path    string `json:"path" jsonschema:"file path relative to the workspace root"`
	Content string `json:"content" jsonschema:"full new content of the file"`
}
type writeOut struct {
	BytesWritten int `json:"bytes_written"`
}
```
Algorithm:
1. If `p == "."` → error `write_file: path is required`.
2. If `len(Content) > MaxWriteBytes` → error `write_file %s: content is %d bytes, limit is %d`.
3. `if dir := path.Dir(p); dir != "." { root.MkdirAll(dir, 0o755) }` (errors → `write_file %s: %w`).
4. `root.WriteFile(p, []byte(Content), 0o644)` (errors → `write_file %s: %w`).
5. Return `nil, writeOut{BytesWritten: len(Content)}, nil`.

Risk classes (configured by the agent config, documented here so 0.9.1's
example matches): `read_file` → `read`, `list_dir` → `read`, `write_file` → `write_local`.

### `adlc tool fs` (file `internal/cli/tool.go`)

```go
func newToolCmd() *cobra.Command   // "tool": "Run a built-in MCP tool server over stdio"; no RunE; has subcommand fs
func newToolFSCmd() *cobra.Command // "fs": flags below
```
Flags: `--root` (string, required, `MarkFlagRequired`), `--max-read-bytes`
(int64, 0), `--max-write-bytes` (int64, 0), `--max-entries` (int, 0).
`RunE`:
1. `abs, err := filepath.Abs(root)`; `r, err := os.OpenRoot(abs)` (error → `fs: open root %s: %w`).
2. `defer r.Close()`.
3. `ctx, stop := signal.NotifyContext(cmd.Context(), os.Interrupt, syscall.SIGTERM); defer stop()`.
4. `return fstools.NewServer(r, opts).Run(ctx, &mcp.StdioTransport{})`.
   (Import the package as `fstools` to avoid clashing with `io/fs`.)
5. If `Run` returns an error caused by the client closing stdin, treat it as
   a clean exit: return nil when `ctx.Err() != nil` or `errors.Is(err, io.EOF)`.

Nothing may write to stdout except the MCP transport.

## Out of scope

- Deleting, moving or renaming files; editing part of a file (later tasks may add `edit_file`).
- Running commands (task 1.5).
- Binary files.

## Pitfalls

- Use `os.Root` for **every** file access. Never join paths yourself with `filepath.Join(rootDir, p)` — that is how escapes happen.
- `fs.ReadDir(root.FS(), p)` needs a path valid for `io/fs` (no leading `/`, no `..`). `cleanPath` guarantees that; call it first in every handler.
- A nil slice encodes as `null` in JSON. Initialise `Entries` with `[]entry{}`.
- Stdout belongs to the MCP protocol; `fmt.Println` anywhere in this command breaks the client.
- `TestMain` must call `os.Exit(m.Run())` in the normal path.
