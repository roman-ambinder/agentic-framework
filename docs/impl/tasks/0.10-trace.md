# 0.10 — Trace export and `adlc trace`

Size: M · Depends on: 0.9.2 · Branch: `task/0.10-trace` · PR title: `0.10: trace export and adlc trace`

## Goal

After this task, a finished (or still running) run can be shown as a span
tree. `adlc trace RUN_ID` prints a deterministic text tree built from the
event log, and `adlc trace RUN_ID --otel-stdout` prints the same tree as
OpenTelemetry spans (JSON) using the OTel stdout exporter. Spans are built
**after the fact** from events; nothing is traced live.

### Intermediate model (`span.go`)

One conversion from events to a tree; both outputs use it.

```go
package observability

// SpanKind is what a Span represents.
type SpanKind string

const (
	KindRun   SpanKind = "run"
	KindModel SpanKind = "model"
	KindTool  SpanKind = "tool"
)

// Span is one node of a run's trace.
type Span struct {
	Kind     SpanKind
	Name     string    // see "Span names" below
	Start    time.Time
	End      time.Time // zero if the span never ended (run still going, call in flight)
	Attrs    []attribute.KeyValue // in the order listed below
	Failed   bool                 // true → OTel status Error
	Status   string               // short text for the tree, see below
	Events   []SpanEvent          // point-in-time events, in log order
	Children []*Span              // run span only; in log order of their first event
}

// SpanEvent is a point-in-time event on a span.
type SpanEvent struct {
	Name  string
	Time  time.Time
	Attrs []attribute.KeyValue
}

// ErrNotARun is returned by Build when the events do not start with run_started.
var ErrNotARun = errors.New("observability: events do not start with run_started")

// Build turns one run's events (seq order, from seq 1) into a span tree.
func Build(events []*adlcv1.Event) (*Span, error)
```

### `Build` algorithm

1. If `len(events) == 0` or `events[0].GetRunStarted() == nil`, return `nil, ErrNotARun`.
2. Create `root := &Span{Kind: KindRun, Name: "run " + runID, Start: events[0].Time.AsTime()}`.
   Attributes on root (set at step 6): `adlc.run_id`, `adlc.agent_id`, `adlc.agent_version`, `adlc.task`.
3. Keep `openModel map[string]*Span` (key `call_id`) and `openTool map[string]*Span` (key tool call id).
4. Walk events in order. For each event `ev` with time `t := ev.GetTime().AsTime()`:
   - `model_call_started`: `s := &Span{Kind: KindModel, Name: "model " + call_id, Start: t}` with attrs
     `adlc.call_id`, `adlc.step` (int64), `adlc.attempt` (int64), `adlc.provider`, `adlc.model`;
     `openModel[call_id] = s`; append to `root.Children`.
   - `model_call_completed`: `s := openModel[call_id]`; if missing, return
     `fmt.Errorf("observability: seq %d: model_call_completed for %q without start", seq, call_id)`.
     Set `s.End = t`; append attrs `adlc.finish_reason` (enum `String()`), and the event's cost:
     `adlc.input_tokens`, `adlc.output_tokens`, `adlc.cache_read_tokens`, `adlc.cache_write_tokens`, `adlc.usd_micros`
     (all int64, always present, 0 if no cost). `s.Status = <finish reason without the "FINISH_REASON_" prefix, lowercased>`
     (e.g. `tool_use`). Delete from `openModel`.
   - `model_call_failed`: same lookup and error text with `model_call_failed`. `s.End = t`, `s.Failed = true`,
     attrs `adlc.error_class` (String()), `adlc.will_retry` (bool), `adlc.http_status` (int64);
     `s.Status = "failed: " + message`. Delete from `openModel`.
   - `tool_call_requested`: `s := &Span{Kind: KindTool, Name: "tool " + call.id + " " + call.name, Start: t}`,
     attrs `adlc.call_id`, `adlc.tool`, `adlc.server`, `adlc.risk_class` (String()); `openTool[id] = s`;
     append to `root.Children`.
   - `policy_decided`: add `SpanEvent{Name: "policy", Time: t, Attrs: [adlc.decision, adlc.rule_id, adlc.reason, adlc.source]}`
     to `openTool[call_id]` (if missing, add it to root instead). If the decision is `DENY`, also set that
     tool span's `End = t`, `Failed = true`, `Status = "denied"` and delete it from `openTool`.
   - `tool_call_completed`: lookup `openTool[call_id]`; if missing return
     `fmt.Errorf("observability: seq %d: tool_call_completed for %q without request", seq, call_id)`.
     `End = t`; attrs `adlc.is_error` (bool), `adlc.exit_code` (int64), `adlc.output_bytes` (int64 = len(output)),
     `adlc.truncated_for_model` (bool). `Status = "ok"` or `"error"`; `Failed = is_error`.
   - `approval_requested`, `approval_resolved`, `checkpoint`, `error_occurred`: add a `SpanEvent` to root named
     `approval_requested`, `approval_resolved`, `checkpoint`, `error` with their main fields as attrs
     (`adlc.approval_id`, `adlc.approved`, `adlc.step`, `adlc.message`, ...). `error_occurred` also sets `root.Failed = true`.
   - `run_completed`: `root.End = t`; attrs `adlc.stop_reason` (String()), `adlc.exhausted_budget` (String(), only if not UNSPECIFIED);
     `root.Status = <stop reason without "STOP_REASON_" prefix, lowercased>`; `Failed = stop reason is ERROR`.
   - unknown kind (`eventlog.Kind(ev) == ""`): ignore.
5. Spans still in `openModel`/`openTool` keep `End` zero and get `Status = "in flight"`.
6. Fold the events with `eventlog.Fold` and add the run's totals to root attrs:
   `adlc.input_tokens`, `adlc.output_tokens`, `adlc.usd_micros`, `adlc.status` (`RunState.Status.String()`).
   If `Fold` fails, return its error wrapped: `fmt.Errorf("observability: %w", err)`.
7. If the run has no `run_completed`, `root.Status = "running"` and `root.End` stays zero.

### Text tree (`tree.go`)

```go
// WriteTree writes root as an indented tree. Output is deterministic:
// no maps are iterated, times are shown as offsets from root.Start.
func WriteTree(w io.Writer, root *Span) error
```

Format, one line per span, children in order:

```
<prefix><name>  [<status>]  +<start offset>  <duration>  <details>
```

- `<prefix>`: root has none; children use `├─ ` and the last child `└─ `.
- `<start offset>`: `Start.Sub(root.Start)` formatted with `formatDur`.
- `<duration>`: `End.Sub(Start)` with `formatDur`, or `-` if `End` is zero.
- `formatDur(d)`: `d.Round(time.Millisecond).String()` (e.g. `1.2s`, `350ms`, `0s`).
- `<details>`: for model spans `<provider>/<model> in=<n> out=<n> $<usd>`; for tool spans `<risk> <decision or "-">`;
  for the root `in=<n> out=<n> $<usd>`. `<usd>` is micro-USD formatted as `fmt.Sprintf("%d.%06d", m/1e6, m%1e6)`.
  `<risk>` is the risk class without the `RISK_CLASS_` prefix, lowercased.
- After a span's line, each of its `Events` is printed on its own line as `<eprefix>· <name> +<offset> <k>=<v> ...`
  with attrs in stored order (`<v>` via `attribute.Value.Emit()`). `<eprefix>` is exactly:
  - root events: two spaces `"  "`;
  - events of a child that is not the last child: `"│    "` (bar + 4 spaces);
  - events of the last child: `"     "` (5 spaces).
- Root events are printed right after the root line, before the first child.
- Lines end with `\n`; no trailing spaces except where an attribute value is empty (`adlc.reason=`).

Example (exact output for the test fixture `fullRun()` in `tree_test.go`):

```
run r1  [completed]  +0s  6s  in=150 out=30 $0.000750
├─ model m1  [tool_use]  +1s  1s  fake/fake-1 in=100 out=20 $0.000500
├─ tool t1 fs__read_file  [ok]  +2s  1s  read allow
│    · policy +2s adlc.decision=DECISION_ALLOW adlc.rule_id=r-read adlc.reason= adlc.source=DECISION_SOURCE_LOCAL
└─ model m2  [end_turn]  +4s  1s  fake/fake-1 in=50 out=10 $0.000250
```

Write the expected string in the test exactly like this and make the code produce it. If you find a
formatting detail not covered here, choose the simplest one, make the test match, and mention it in the PR.

### OpenTelemetry export (`otel.go`)

```go
// Export emits root and its children as OTel spans through tp's tracer
// "github.com/roman-ambinder/agentic-framework/observability", using each
// Span's own Start/End times, then calls tp.ForceFlush.
func Export(ctx context.Context, root *Span, tp *sdktrace.TracerProvider) error

// NewIDGenerator returns an sdktrace.IDGenerator whose trace ID is the first
// 16 bytes of sha256(runID) and whose span IDs are the first 8 bytes of
// sha256(runID + "/" + n) for n = 1, 2, 3, ... in creation order, so the
// same run always exports the same IDs.
func NewIDGenerator(runID string) sdktrace.IDGenerator
```

Steps inside `Export`:
1. `tr := tp.Tracer("github.com/roman-ambinder/agentic-framework/observability")`.
2. Start the root: `ctx, span := tr.Start(ctx, root.Name, trace.WithTimestamp(root.Start), trace.WithAttributes(root.Attrs...), trace.WithSpanKind(trace.SpanKindInternal))`.
3. For each child, start it from the root's `ctx` the same way (this makes it a child), add its events with
   `span.AddEvent(ev.Name, trace.WithTimestamp(ev.Time), trace.WithAttributes(ev.Attrs...))`, set
   `span.SetStatus(codes.Error, s.Status)` if `Failed`, then `span.End(trace.WithTimestamp(end))` where
   `end = s.End`, or `root`'s last event time if `s.End` is zero.
4. Add root events, status, and end the root last (same end rule).
5. `return tp.ForceFlush(ctx)`.

`trace.WithTimestamp` returns a `trace.SpanEventOption`, which is valid for start, end and events.

### `adlc trace` (`internal/cli/trace.go`)

```
adlc trace RUN_ID [--db PATH] [--otel-stdout]
```

- `--db`: same flag name, default and help text as `adlc run` (task 0.9.2). Reuse its constant.
- Exactly one argument (`cobra.ExactArgs(1)`).
- Steps: open the store (`eventlog.Open`), `Read(ctx, runID, 0)`; no events → error
  `run "<id>" not found`; `Build`; then either `WriteTree(cmd.OutOrStdout(), root)` or, with `--otel-stdout`:
  `exp, _ := stdouttrace.New(stdouttrace.WithWriter(cmd.OutOrStdout()), stdouttrace.WithPrettyPrint())`,
  `tp := sdktrace.NewTracerProvider(sdktrace.WithSyncer(exp), sdktrace.WithIDGenerator(NewIDGenerator(runID)))`,
  `Export`, then `tp.Shutdown(ctx)`.

## Out of scope

- Live tracing during a run, OTLP exporters, sending traces anywhere but stdout.
- Showing tool output or model text in the tree.
- Cost reports (task 1.11).

## Pitfalls

- Do not iterate over `openModel`/`openTool` maps when producing output; output order must come from the event order.
- A retried model call reuses the same `call_id`; a new `model_call_started` for an id that is still open is
  impossible in a valid log, but if it happens, end the old span with status `superseded` instead of failing.
- `trace.WithTimestamp` must be passed to `End`; otherwise spans end at `time.Now()` and tests become time-dependent.
- Use `cmd.OutOrStdout()`, never `os.Stdout`, so CLI tests can capture output.
- `stdouttrace` prints timestamps; the OTel CLI test therefore checks for a substring, not a golden file.
