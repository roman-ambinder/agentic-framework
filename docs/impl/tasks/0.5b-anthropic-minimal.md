# 0.5b — Anthropic adapter, minimal

Size: M · Depends on: 0.4 · Branch: `task/0.5b-anthropic-minimal` · PR title: `0.5b: minimal Anthropic model adapter`

## Goal

Package `internal/model/anthropic` implements `model.Adapter` for the
Anthropic Messages API using the official Go SDK, **without streaming**. It
maps requests and responses, keeps thinking blocks as replayable `Blob`s,
maps stop reasons and usage, and classifies errors as in `interfaces.md`
§2.1. All tests use a local `httptest` server; one live smoke test runs only
with `-tags live`.

## Design

```go
package anthropic

const ProviderName = "anthropic"

type Options struct {
	APIKey           string       // "" = the SDK reads ANTHROPIC_API_KEY from the environment
	BaseURL          string       // "" = SDK default; tests use an httptest URL
	HTTPClient       *http.Client // nil = SDK default
	MaxContextTokens int          // reported in Capabilities; 0 = unknown
}

type Adapter struct {
	client sdk.Client
	opts   Options
}

func New(opts Options) *Adapter
func (a *Adapter) Provider() string          // "anthropic"
func (a *Adapter) Capabilities() model.Caps  // {ToolCalling: true, PromptCaching: true, Streaming: false, MaxContextTokens: opts.MaxContextTokens}
func (a *Adapter) Generate(ctx context.Context, req *model.Request) (*model.Response, error)
func (a *Adapter) CountTokens(ctx context.Context, req *model.Request) (int64, error)

var _ model.Adapter = (*Adapter)(nil)
```

`New` builds the client with options in this order: `option.WithMaxRetries(0)`
(always — the harness does retries, task 0.5.3), then `WithAPIKey` if set,
`WithBaseURL` if set, `WithHTTPClient` if set.

### Request mapping (`request.go`)

`Generate` algorithm:

1. If `req.MaxTokens <= 0` → `fmt.Errorf("anthropic: MaxTokens must be > 0")` (plain error, not `*model.Error`).
2. `msgs, err := buildMessages(req.Messages)`.
3. `tools, err := buildTools(req.Tools)`.
4. `eff, err := effort(req.Effort)`.
5. Build:
   ```go
   p := sdk.MessageNewParams{Model: req.Model, MaxTokens: int64(req.MaxTokens), Messages: msgs}
   if req.System != "" { p.System = []sdk.TextBlockParam{{Text: req.System}} }
   if len(tools) > 0 {
       p.Tools = tools
       p.ToolChoice = sdk.ToolChoiceUnionParam{OfAuto: &sdk.ToolChoiceAutoParam{}}
   }
   if eff != "" { p.OutputConfig = sdk.OutputConfigParam{Effort: eff} }
   ```
6. `msg, err := a.client.Messages.New(ctx, p)`; on error return `nil, classify(ctx, err)`.
7. Return `toResponse(msg), nil`.

`buildMessages(msgs []model.Message) ([]sdk.MessageParam, error)`:
for each message, build `blocks []sdk.ContentBlockParamUnion` from its parts, in order:

| Part | Block |
|------|-------|
| `PartText` | `sdk.NewTextBlock(p.Text)` |
| `PartToolCall` | `sdk.NewToolUseBlock(c.ID, args, c.Name)` where `args` is `c.Arguments`, or `json.RawMessage("{}")` if empty |
| `PartToolResult` | `sdk.NewToolResultBlock(r.CallID, r.Content, r.IsError)` |
| `PartBlob` with `Provider == "anthropic"` | `blobBlock(b)` (below) |
| `PartBlob` of another provider | skipped |

Then: if `blocks` is empty, skip the message. Role `user` →
`sdk.NewUserMessage(blocks...)`; `assistant` → `sdk.NewAssistantMessage(blocks...)`;
any other role → error `anthropic: unknown role %q`.

`blobBlock(b model.Blob) (sdk.ContentBlockParamUnion, error)`:
```go
var raw struct {
	Type      string `json:"type"`
	Thinking  string `json:"thinking"`
	Signature string `json:"signature"`
	Data      string `json:"data"`
}
// json.Unmarshal(b.Data, &raw); error -> "anthropic: bad blob: %w"
switch raw.Type {
case "thinking":          return sdk.NewThinkingBlock(raw.Signature, raw.Thinking), nil
case "redacted_thinking": return sdk.NewRedactedThinkingBlock(raw.Data), nil
default:                  return ..., fmt.Errorf("anthropic: unknown blob type %q", raw.Type)
}
```

`buildTools(specs []model.ToolSpec) ([]sdk.ToolUnionParam, error)`: for each spec:
1. `schema := map[string]any{}`; if `len(spec.InputSchema) > 0`, `json.Unmarshal` into it; error → `anthropic: tool %s: input schema: %w`.
2. `in := sdk.ToolInputSchemaParam{Properties: schema["properties"]}`.
3. `required`: if `schema["required"]` is a `[]any` of strings, copy into `in.Required`.
4. Every other key except `"type"`, `"properties"`, `"required"` goes into `in.ExtraFields` (create the map only if needed).
5. `tp := &sdk.ToolParam{Name: spec.Name, InputSchema: in}`; if `spec.Description != ""`, `tp.Description = sdk.String(spec.Description)`.
6. Append `sdk.ToolUnionParam{OfTool: tp}`.

`effort(s string) (sdk.OutputConfigEffort, error)`: `""` → `""`;
`low|medium|high|xhigh|max` → `sdk.OutputConfigEffort(s)`; anything else →
`anthropic: unknown effort %q`.

### Response mapping (`response.go`)

`toResponse(msg *sdk.Message) *model.Response`:
1. For each block in `msg.Content`, by `block.Type`:
   - `"text"` → `model.TextPart(block.Text)`
   - `"tool_use"` → `model.ToolCallPart(model.ToolCall{ID: block.ID, Name: block.Name, Arguments: copy of block.Input, or "{}" if empty})`
   - `"thinking"`, `"redacted_thinking"` → `model.BlobPart(model.Blob{Provider: "anthropic", Kind: block.Type, Data: []byte(block.RawJSON())})`
   - anything else → skipped
2. `Message.Role = model.RoleAssistant`.
3. `Finish = finishReason(msg.StopReason)`; `ProviderFinish = string(msg.StopReason)`.
4. `Usage = model.Usage{InputTokens: u.InputTokens, OutputTokens: u.OutputTokens, CacheReadTokens: u.CacheReadInputTokens, CacheWriteTokens: u.CacheCreationInputTokens}`.

`finishReason`:

| `stop_reason` | `adlcv1.FinishReason` |
|---------------|-----------------------|
| `end_turn`, `stop_sequence` | `FINISH_REASON_END_TURN` |
| `tool_use` | `FINISH_REASON_TOOL_USE` |
| `max_tokens`, `model_context_window_exceeded` | `FINISH_REASON_MAX_TOKENS` |
| `refusal` | `FINISH_REASON_REFUSAL` |
| `pause_turn` | `FINISH_REASON_PAUSED` |
| anything else | `FINISH_REASON_OTHER` |

### Errors (`errors.go`)

`classify(ctx context.Context, err error) error`:
1. If `ctx.Err() != nil` → return `ctx.Err()` (not wrapped in `*model.Error`; `model.IsRetryable` already treats it as not retryable).
2. `var apiErr *sdk.Error`; if `errors.As(err, &apiErr)`:
   - 429 → `Class RATE_LIMIT`, retryable
   - 408, 500, 502, 503, 504, 529 → `Class MODEL`, retryable
   - any other status → `Class MODEL`, not retryable
   - `HTTPStatus = apiErr.StatusCode`, `Err = err`
3. Otherwise, if `errors.As(err, new(net.Error))` or `errors.As(err, new(*url.Error))` → `Class TIMEOUT`, retryable, `Err = err`.
4. Otherwise → `Class MODEL`, not retryable, `Err = err`.

Return a `*model.Error`.

### `CountTokens`

Build messages/tools/system with the same helpers, then
```go
p := sdk.MessageCountTokensParams{Model: req.Model, Messages: msgs}
if req.System != "" { p.System = sdk.MessageCountTokensParamsSystemUnion{OfTextBlockArray: []sdk.TextBlockParam{{Text: req.System}}} }
for _, t := range tools { p.Tools = append(p.Tools, sdk.MessageCountTokensToolUnionParam{OfTool: t.OfTool}) }
res, err := a.client.Messages.CountTokens(ctx, p)   // error -> classify
return res.InputTokens, nil
```

## Out of scope

- Streaming, prompt caching markers, task budgets (task 1.1).
- Retries (task 0.5.3 — the SDK's own retries are turned off on purpose).
- Server-side tools (web search, code execution), images, documents.
- Choosing a model id: it always comes from config (`Request.Model`).

## Pitfalls

- Keep `option.WithMaxRetries(0)`: two retry layers multiply waiting time and hide failures from the event log.
- Never force a tool call (`OfAny`, `OfTool` in `ToolChoice`): some models reject it.
- Thinking blocks must be replayed **byte-for-byte equivalent and in their original position**; that is why parts keep the response's block order.
- `block.Input` is a `json.RawMessage` that may share memory with the SDK's buffer: copy it (`append(json.RawMessage(nil), block.Input...)`).
- Tests must pass `APIKey: "test-key"` so the SDK never picks up real credentials from the environment.
- Do not put any real model id in code or tests; live tests read it from `ADLC_LIVE_ANTHROPIC_MODEL`.
