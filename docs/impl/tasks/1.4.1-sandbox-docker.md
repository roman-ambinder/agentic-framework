# 1.4.1 — Sandbox interface and Docker backend

Size: M · Depends on: 0.0 · Branch: `task/1.4.1-sandbox-docker` · PR title: `1.4.1: sandbox interface and Docker backend`

## Goal

After this task the repo has:

- `internal/sandbox`: the `Sandbox` interface from `interfaces.md §8`, plus the
  label constants and helpers every backend uses.
- `internal/sandbox/sandboxtest`: two **test-only** implementations
  (`Host`, which runs commands on the host in a temp dir, and `Scripted`,
  which returns canned results) and a conformance test suite any backend can run.
- `internal/sandbox/docker`: a Docker backend that creates a long-running
  container, runs commands in it with a timeout, copies files out, finds
  containers by run id and removes them.

Isolation (no network, CPU/memory limits, non-root user, copying the
workspace in) is **task 1.4.2**. In this task, `Spec.Network`, `Spec.CPUs`,
`Spec.MemoryBytes` and `Spec.WorkspaceDir` are not applied yet (see Design).

## Design

### `internal/sandbox/sandbox.go`

Copy the types from `interfaces.md §8` exactly, and add **one field to
`Spec`** (this is a change to `interfaces.md §8`; update that file in this PR
and say so in the PR description):

```go
type Spec struct {
	RunID        string            // required; stored as label adlc.run_id
	Image        string            // required, e.g. "golang:1.26"
	WorkspaceDir string            // host dir copied into /workspace (task 1.4.2)
	CPUs         float64           // 0 = no limit (task 1.4.2)
	MemoryBytes  int64             // 0 = no limit (task 1.4.2)
	Network      bool              // false = no network (task 1.4.2)
	Env          map[string]string // the only environment the container gets
}
```

Add, in the same file:

```go
// Labels put on every container this project creates.
const (
	LabelManaged = "adlc.managed" // value "true"
	LabelRunID   = "adlc.run_id"
)

// WorkspacePath is where the workspace lives inside every sandbox.
const WorkspacePath = "/workspace"

// MaxOutputBytes caps ExecResult.Stdout and ExecResult.Stderr each.
const MaxOutputBytes = 8 << 20 // 8 MiB

// TruncatedMarker is appended to Stdout/Stderr when they were capped.
const TruncatedMarker = "\n[output truncated by sandbox]\n"

var (
	// ErrInvalidSpec means Create was called with a bad Spec.
	ErrInvalidSpec = errors.New("sandbox: invalid spec")
	// ErrNotFound means the handle does not name a live sandbox.
	ErrNotFound = errors.New("sandbox: not found")
)

// Validate checks the fields every backend needs.
func (s Spec) Validate() error
```

`Validate` returns `fmt.Errorf("%w: %s", ErrInvalidSpec, reason)` with these
exact reasons, checked in this order:

1. `RunID == ""` → `"run id is empty"`
2. `Image == ""` → `"image is empty"`
3. `CPUs < 0` → `"cpus must not be negative"`
4. `MemoryBytes < 0` → `"memory must not be negative"`

Add a helper used by every backend to cap output:

```go
// CapOutput returns b unchanged if len(b) <= max, otherwise the first max
// bytes followed by TruncatedMarker.
func CapOutput(b []byte, max int) []byte
```

Exec semantics every backend must follow (write them as the doc comment on
`Sandbox.Exec`):

- `cmd` is an argv list, run with working directory `WorkspacePath`.
- `timeout` must be > 0; on expiry the command is killed, the call returns
  normally with `TimedOut: true` and a non-zero `ExitCode`.
- A command that runs and exits non-zero is **not** an error: the error
  return is only for "could not run at all" (sandbox gone, daemon down, ctx
  cancelled by the caller).
- `Stdout`/`Stderr` are capped with `CapOutput(…, MaxOutputBytes)`.

### `internal/sandbox/sandboxtest`

Put this at the top of `host.go`:

```go
// Host is a Sandbox that runs commands directly on the host, in a temporary
// copy of the workspace. It provides NO isolation. Use it only in tests.
```

```go
type Host struct {
	// Dir is the parent of all workspaces; set it to t.TempDir().
	Dir string
	// unexported: mutex, map[string]string handle id → workspace dir, counter
}

func NewHost(dir string) *Host
func (h *Host) Create(ctx context.Context, spec sandbox.Spec) (sandbox.Handle, error)
func (h *Host) Exec(ctx context.Context, hd sandbox.Handle, cmd []string, timeout time.Duration) (sandbox.ExecResult, error)
func (h *Host) CopyOut(ctx context.Context, hd sandbox.Handle, path string) ([]byte, error)
func (h *Host) Destroy(ctx context.Context, hd sandbox.Handle) error
// WorkspaceDir returns the host directory that plays /workspace for hd.
func (h *Host) WorkspaceDir(hd sandbox.Handle) (string, error)
```

Host behaviour:

- `Create`: `spec.Validate()`; make `<Dir>/sb-<n>/workspace` (n counts from 1);
  if `spec.WorkspaceDir != ""`, copy that tree into it (regular files and
  directories only; skip symlinks). Handle ID is `"host-<n>"`.
- `Exec`: `exec.CommandContext` with `Dir` = the workspace dir, `Env` =
  `spec.Env` as `KEY=VALUE` plus `PATH` from the host (tests need `git`,
  `grep`). Timeout via `context.WithTimeout`; `TimedOut` = the timeout
  context's `Err()` is `context.DeadlineExceeded`. Use `cmd.WaitDelay = time.Second`
  so a killed command's pipes close. Exit code from `*exec.ExitError`
  (`ExitCode()`), `-1` if killed by signal. An unknown handle →
  `ErrNotFound`. Paths inside commands must be relative (there is no real
  `/workspace` on the host); document this in the doc comment.
- `CopyOut(path)`: `path` must be `WorkspacePath` or start with
  `WorkspacePath + "/"`; map it to the host dir and return a tar archive of
  it (use `archive/tar`; entry names relative to the parent of `path`, the
  same as `docker cp` produces, e.g. `workspace/main.go`).
- `Destroy`: `os.RemoveAll` of `<Dir>/sb-<n>`; unknown handle → `ErrNotFound`.

`Scripted` (for unit tests of tools that only need to check which command ran):

```go
type Scripted struct {
	// Results maps strings.Join(cmd, " ") to the result to return.
	Results map[string]sandbox.ExecResult
	// unexported: recorded calls
}
func (s *Scripted) Exec(ctx context.Context, h sandbox.Handle, cmd []string, timeout time.Duration) (sandbox.ExecResult, error)
func (s *Scripted) Calls() [][]string
// Create returns Handle{ID: "scripted"}; CopyOut returns an empty tar; Destroy returns nil.
```

An unknown command → error `fmt.Errorf("sandboxtest: no scripted result for %q", key)`.

Conformance suite:

```go
// RunConformance checks behaviour every Sandbox must have. newSpec returns a
// valid Spec (backends choose the image).
func RunConformance(t *testing.T, sb sandbox.Sandbox, newSpec func() sandbox.Spec)
```

Subtests (names exact):

| Subtest | Asserts |
|---------|---------|
| `ExecStdoutStderrExitCode` | `sh -c 'echo out; echo err >&2; exit 3'` → Stdout `"out\n"`, Stderr `"err\n"`, ExitCode 3, err nil |
| `ExecWorkingDirIsWorkspace` | `sh -c 'pwd'` → on Docker `"/workspace\n"`; on Host, ends with `"/workspace\n"` |
| `ExecTimeout` | `sh -c 'sleep 30'` with timeout 1s → returns within 10s, `TimedOut` true, ExitCode != 0 |
| `ExecOutputIsCapped` | `sh -c 'head -c 9000000 /dev/zero'` → `len(Stdout) == MaxOutputBytes+len(TruncatedMarker)` and ends with the marker |
| `ExecEnv` | Spec.Env `{"ADLC_X":"1"}`; `sh -c 'echo $ADLC_X'` → `"1\n"` |
| `CreateRejectsInvalidSpec` | Spec with empty RunID → `errors.Is(err, sandbox.ErrInvalidSpec)` |
| `DestroyThenExecFails` | after Destroy, Exec → `errors.Is(err, sandbox.ErrNotFound)` |

Each subtest creates its own sandbox and destroys it in `t.Cleanup`.

### `internal/sandbox/docker`

```go
package docker

// ErrUnavailable means the Docker daemon cannot be reached.
var ErrUnavailable = errors.New("docker: daemon unavailable")

// Backend is a sandbox.Sandbox backed by Docker containers.
type Backend struct {
	cli *client.Client
	// unexported: map handle id → Spec, guarded by a mutex (needed by 1.4.2)
}

// New connects to the daemon from the environment (DOCKER_HOST etc.) and
// pings it. If the ping fails it returns an error wrapping ErrUnavailable.
func New(ctx context.Context) (*Backend, error)

func (b *Backend) Close() error
func (b *Backend) Create(ctx context.Context, spec sandbox.Spec) (sandbox.Handle, error)
func (b *Backend) Exec(ctx context.Context, h sandbox.Handle, cmd []string, timeout time.Duration) (sandbox.ExecResult, error)
func (b *Backend) CopyOut(ctx context.Context, h sandbox.Handle, path string) ([]byte, error)
func (b *Backend) Destroy(ctx context.Context, h sandbox.Handle) error

// FindByRunID returns the containers labelled with runID (running or not).
func (b *Backend) FindByRunID(ctx context.Context, runID string) ([]sandbox.Handle, error)
// Cleanup force-removes every container labelled with runID and returns how
// many it removed. runID "" removes every container with LabelManaged.
func (b *Backend) Cleanup(ctx context.Context, runID string) (int, error)
```

Library calls (all verified against `github.com/moby/moby/client` v0.6.3):

| Need | Call |
|------|------|
| connect | `client.New(client.FromEnv, client.WithAPIVersionNegotiation())` |
| ping | `cli.Ping(ctx, client.PingOptions{})` |
| image present? | `cli.ImageInspect(ctx, image)`; missing when `cerrdefs.IsNotFound(err)` (`cerrdefs "github.com/containerd/errdefs"`) |
| pull | `resp, err := cli.ImagePull(ctx, image, client.ImagePullOptions{})`, then `resp.Wait(ctx)`, then `resp.Close()` |
| create | `cli.ContainerCreate(ctx, client.ContainerCreateOptions{Config: &container.Config{...}, HostConfig: &container.HostConfig{...}, Name: name})` → `.ID` (`container "github.com/moby/moby/api/types/container"`) |
| start | `cli.ContainerStart(ctx, id, client.ContainerStartOptions{})` |
| exec | `cli.ExecCreate(ctx, id, client.ExecCreateOptions{Cmd, Env, WorkingDir, AttachStdout: true, AttachStderr: true})` → `.ID`; `cli.ExecAttach(ctx, execID, client.ExecAttachOptions{})` (this **starts** the exec; do not also call `ExecStart`); read `res.Reader` with `stdcopy.StdCopy(&stdout, &stderr, res.Reader)` (`"github.com/moby/moby/api/pkg/stdcopy"`); `res.Close()`; then `cli.ExecInspect(ctx, execID, client.ExecInspectOptions{})` → `.ExitCode`, `.Running` |
| copy out | `cli.CopyFromContainer(ctx, id, client.CopyFromContainerOptions{SourcePath: path})` → `.Content` (a tar stream; read all, close) |
| list by label | `cli.ContainerList(ctx, client.ContainerListOptions{All: true, Filters: client.Filters{}.Add("label", sandbox.LabelRunID+"="+runID)})` → `.Items[i].ID` |
| remove | `cli.ContainerRemove(ctx, id, client.ContainerRemoveOptions{Force: true})` |

Container settings in this task (`Create`):

```go
cfg := &container.Config{
	Image:      spec.Image,
	Cmd:        []string{"sh", "-c", "while :; do sleep 3600; done"},
	WorkingDir: sandbox.WorkspacePath,
	Env:        envList(spec.Env), // sorted KEY=VALUE
	Labels: map[string]string{
		sandbox.LabelManaged: "true",
		sandbox.LabelRunID:   spec.RunID,

}

```

`sanitize` keeps `[a-zA-Z0-9_.-]` and replaces anything else with `-`.
The keep-alive command uses `sh` so it works on any image with a shell
(`sleep infinity` is not supported by every `sleep`).

If `spec.WorkspaceDir != ""`, `CPUs != 0`, `MemoryBytes != 0` or `Network`
is false, **do not apply them yet**. Add the comment
`// Applied in task 1.4.2.` where 1.4.2 will add the code. (1.4.2 makes
`Network: false` mean no network; until then containers use the default network.)

### Exec algorithm (`exec.go`)

1. Look up the handle; if unknown to this Backend, still try (handles can
   come from `FindByRunID` in another process).
2. If `timeout <= 0` return `fmt.Errorf("docker: exec timeout must be > 0")`.
3. Build the command: `["timeout", "-s", "KILL", strconv.Itoa(secs)] + cmd`,
   with `secs = int(math.Ceil(timeout.Seconds()))`. `timeout` exists in
   busybox and coreutils; images without it are not supported (say so in the
   doc comment).
4. Make `execCtx, cancel := context.WithTimeout(ctx, timeout+10*time.Second)`
   (backstop if the daemon hangs).
5. `ExecCreate` with `Env` = the container's spec env (if known) and
   `WorkingDir: sandbox.WorkspacePath`. If the container does not exist
   (`cerrdefs.IsNotFound(err)`), return an error wrapping `sandbox.ErrNotFound`.
6. `start := time.Now()`; `ExecAttach`; `StdCopy` into two
   `limitedBuffer`s (a `bytes.Buffer` wrapper that keeps the first
   `MaxOutputBytes+1` bytes and discards the rest while still reporting the
   full length as written, so `StdCopy` keeps draining the stream).
7. `ExecInspect`; poll every 50 ms (max 2 s) while `.Running` is true.
8. `TimedOut = time.Since(start) >= timeout && ExitCode != 0`.
9. Cap both buffers with `sandbox.CapOutput`.
10. If the caller's `ctx` was cancelled, return `ctx.Err()`.

## Out of scope

- Network isolation, CPU/memory limits, non-root user, copying the workspace
  in, `Spec.WorkspaceDir` (task 1.4.2).
- Tools that use the sandbox (task 1.5); resuming runs (task 1.7).
- Snapshots of a sandbox; any other backend (Kubernetes, microVMs).
- A CLI command for sandboxes.

## Pitfalls

- `ExecAttach` starts the exec. Calling `ExecStart` as well runs nothing or fails.
- The attach stream is multiplexed (stdout and stderr frames). Reading
  `res.Reader` directly gives garbage headers; always use `stdcopy.StdCopy`.
- `ExecInspect` can still report `Running: true` right after the stream
  ends; poll briefly before reading `ExitCode`.
- A killed exec keeps running inside the container unless something kills it:
  that is why the command is wrapped in `timeout -s KILL`. A context deadline
  alone does **not** stop the process in the container.
- Never return an error for a non-zero exit code.
- Do not leak containers: every test registers `Cleanup`, and `Create` must
  remove the container if `ContainerStart` fails.
- `client.Filters{}` is read-only when empty; always build it with `.Add(...)`.
- `Host` is unsafe by design: never use it outside `_test.go` files and the
  `sandboxtest` package.
