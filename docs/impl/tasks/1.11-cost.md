## Goal

After this task, `adlc cost` reports tokens and money spent, per run, per
model or per agent, read only from the event log. Totals always equal the sum
of the `cost` fields of the events, so the report can be trusted for budgets.

### `internal/costreport` API (exact)

```go
package costreport

// By is how rows are grouped.
type By string

const (
	ByRun   By = "run"
	ByModel By = "model"
	ByAgent By = "agent"
)

// Row is one line of the report. Key is the run id, "<provider>/<model>",
// or the agent id, depending on By.
type Row struct {
	Key              string `json:"key"`
	Runs             int    `json:"runs"`        // number of distinct runs contributing
	ModelCalls       int    `json:"model_calls"` // number of model_call_completed events
	InputTokens      int64  `json:"input_tokens"`
	OutputTokens     int64  `json:"output_tokens"`
	CacheReadTokens  int64  `json:"cache_read_tokens"`
	CacheWriteTokens int64  `json:"cache_write_tokens"`
	USDMicros        int64  `json:"usd_micros"`
}

// Report is the whole result. Rows are sorted by Key ascending.
type Report struct {
	By    By    `json:"by"`
	Rows  []Row `json:"rows"`
	Total Row   `json:"total"` // Key "TOTAL"; Runs = distinct runs overall
}

// Build groups the cost of the given runs. runs maps run id → its events
// (seq order). It returns an error for an unknown By value.
func Build(by By, runs map[string][]*adlcv1.Event) (Report, error)

// WriteText writes the report as an aligned table.
func WriteText(w io.Writer, r Report) error

// WriteJSON writes the report as indented JSON (two spaces) and a newline.
func WriteJSON(w io.Writer, r Report) error
```

### `Build` algorithm

1. Validate `by`; otherwise `fmt.Errorf("costreport: unknown grouping %q (want run, model or agent)", by)`.
2. Iterate run ids **in sorted order** (never range over the map directly when producing output).
3. For each run, walk its events in order, keeping `modelOf map[string]string` (model `call_id` → `"<provider>/<model>"`,
   set on every `model_call_started`).
4. For every event with a non-nil `cost`, choose the key:
   - `ByRun`: the run id.
   - `ByAgent`: the run's `agent_id` (from its `run_started` event's envelope `agent_id`; `"(unknown)"` if empty).
   - `ByModel`: for `model_call_completed` and `model_call_failed`, `modelOf[call_id]`; for any other event
     (or an unknown call id), `"(other)"`.
   Add all five cost fields to that row and to `Total`.
5. Count `ModelCalls` on `model_call_completed` events, keyed the same way.
6. `Runs` per row = number of distinct run ids that added anything to that row (track with a `map[string]struct{}`
   per row). `Total.Runs` = number of runs passed in.
7. Rows with all-zero numbers and zero model calls are dropped. Sort rows by `Key`.

### Text format (exact)

Use `tabwriter.NewWriter(w, 0, 0, 2, ' ', 0)`. Header depends on grouping: `RUN`, `MODEL` or `AGENT`.

```
RUN  RUNS  CALLS  INPUT  OUTPUT  CACHE_READ  CACHE_WRITE  USD
r1   1     2      150    30      0           0            0.000750
r2   1     1      10     5       80          0            0.000040
TOTAL  2   3      160    35      80          0            0.000790
```

Each row is `Key\tRuns\tModelCalls\tInput\tOutput\tCacheRead\tCacheWrite\tUSD\t\n` and the total row is written the
same way with Key `TOTAL`, **through the same tabwriter**, so columns align (the sketch above is not aligned; the test
compares against what tabwriter produces for the fixture). USD is `fmt.Sprintf("%d.%06d", m/1_000_000, m%1_000_000)`;
for negative values (never expected) print a leading `-` and use the absolute value. Call `Flush` at the end.

### `adlc cost` command

```
adlc cost [RUN_ID ...] [--db PATH] [--by run|model|agent] [--json]
```

- No run ids → all runs from `Store.Runs`.
- `--by` default `run`.
- An id with no events → error `run "<id>" not found`, exit 1, nothing printed on stdout.
- Empty log and no ids → prints the header and a `TOTAL` row of zeros (text) or `"rows": []` (JSON).

## Tests

`internal/costreport/costreport_test.go`:
- `TestBuildByRun` — two runs; row values equal hand-computed sums; `Total` equals the sum of rows.
- `TestBuildByModel` — run with two model calls on `fake/a` and one on `fake/b`, plus a cost on an `error_occurred`
  event: rows `(other)`, `fake/a`, `fake/b` in that order with the right sums and `ModelCalls` 0, 2, 1.
- `TestBuildByAgent` — two runs of agent `coder@1` and one of `coder@2`: two rows; `Runs` = 2 and 1.
- `TestBuildRetriedCallSameModel` — `model_call_failed` with cost and a retried `model_call_completed` for the same
  `call_id` both land on that call's model.
- `TestTotalMatchesEventSum` — for a generated log of 50 events with varied costs, `Total.USDMicros` equals the sum
  of every event's `cost.usd_micros` (same for each token field), for all three groupings.
- `TestBuildUnknownGrouping` — `By("day")` returns an error containing `unknown grouping`.
- `TestWriteTextGolden` — compares `WriteText` output for the `TestBuildByRun` fixture to a string literal in the test.
- `TestWriteJSON` — output decodes back into an equal `Report`; ends with `"\n"`.

`internal/cli/cost_test.go`:
- `TestCostAllRuns` — temp DB with two runs; `adlc cost --db <path>` exit 0, output has rows for both and `TOTAL`.
- `TestCostSelectedRunJSON` — `adlc cost r1 --json --db <path>`: valid JSON, one row with key `r1`.
- `TestCostUnknownRun` — exit 1, stderr contains `not found`, stdout empty.
- `TestCostBadGrouping` — `--by day`: exit 1.

## Out of scope

- Prices: costs are already computed when events are written (`model.Price.Cost`, task 0.4/0.5.1). Never recompute here.
- Date filters, budgets, charts.

## Pitfalls

- Do not use `RunState.Usage` for `ByModel`: it has no per-model split. Use the events (it is fine to cross-check
  `ByRun` totals against `RunState.Usage` in a test).
- Ranging over Go maps gives random order; sort keys before writing anything.
- The `TOTAL` row must go through the same `tabwriter` as the rows, or it will not line up.
