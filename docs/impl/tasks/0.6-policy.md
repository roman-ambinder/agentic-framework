### AllowAll

`Authorize` returns `Decision{Decision: DECISION_ALLOW, RuleID: "allow-all",
Reason: "all calls allowed", Source: DECISION_SOURCE_LOCAL}` and nil, unless
`ctx.Err() != nil`, then `Decision{}, ctx.Err()`.

### NewStatic validation

Return an error (message prefix `policy: `) when:
- `def == DECISION_UNSPECIFIED` → `policy: default decision is unspecified`
- a rule has empty `ID` → `policy: rule <index> has no id`
- two rules share an `ID` → `policy: duplicate rule id "<id>"`
- a rule's `Decision == DECISION_UNSPECIFIED` → `policy: rule "<id>" has no decision`
- `ID == "default"` (reserved) → `policy: rule id "default" is reserved`

The returned `Static` holds a **copy** of `rules`.

### Static.Authorize algorithm

1. If `ctx.Err() != nil` → return `Decision{}, ctx.Err()`.
2. If `req.Risk == RISK_CLASS_UNSPECIFIED` → return
   `Decision{DENY, RuleID: "unspecified-risk", Reason: "tool has no risk class", Source: LOCAL}`, nil.
3. For each rule in order: it matches when
   `(rule.Risk == UNSPECIFIED || rule.Risk == req.Risk) && (rule.Tool == "" || rule.Tool == req.Tool)`.
   First match → `Decision{rule.Decision, rule.ID, "matched rule " + rule.ID, LOCAL}`, nil.
4. No match → `Decision{s.Default, "default", "no rule matched", LOCAL}`, nil.

Tool matching is exact string equality on the namespaced name (`fs__write_file`). No wildcards.

### Names

| String | RiskClass | | String | Decision |
|--------|-----------|-|--------|----------|
| `read` | `RISK_CLASS_READ` | | `allow` | `DECISION_ALLOW` |
| `write_local` | `RISK_CLASS_WRITE_LOCAL` | | `deny` | `DECISION_DENY` |
| `write_external` | `RISK_CLASS_WRITE_EXTERNAL` | | `needs_approval` | `DECISION_NEEDS_APPROVAL` |
| `exec` | `RISK_CLASS_EXEC` | | | |
| `irreversible` | `RISK_CLASS_IRREVERSIBLE` | | | |

Parsing is exact (case-sensitive, no trimming). Unknown → error
`fmt.Errorf("%w: risk class %q (want one of read, write_local, write_external, exec, irreversible)", ErrUnknownName, s)`
and similarly `decision %q (want one of allow, deny, needs_approval)`.
`RiskClassName` / `DecisionName` return the strings above, and `"unspecified"`
for UNSPECIFIED or any unknown value.

## Out of scope

- Approvals queue, control plane, remote policy (M2).
- Matching on arguments, wildcards or regexes.
- Reading policy from YAML (task 0.9.1 calls these parsers).

## Pitfalls

- Protobuf enum zero values are `*_UNSPECIFIED`; an unset `Rule.Risk` means "any risk" — test it explicitly.
- Do not return a nil error together with an empty `Decision`; every non-error return has a non-UNSPECIFIED `Decision`.
- `policy` must not import `internal/harness` or `internal/toolrouter`.
