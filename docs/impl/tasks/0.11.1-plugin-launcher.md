# 0.11.1 — Plugin contract and Go launcher

Size: M · Depends on: 0.5.4 · Branch: `task/0.11.1-plugin-launcher` · PR title: `0.11.1: hook plugin contract and launcher`

## Goal

After this task, a harness hook can live in a separate process written in any
language. The contract is a gRPC service, `adlc.v1.HookService`, defined in
`contracts/proto/adlc/v1/plugin.proto`. The Go package `internal/plugin`
starts a plugin process, connects to it over a Unix socket and exposes it as a
`harness.Hook`. A crashing or slow plugin cannot take down the harness: every
failure becomes an error the harness records.

## Design

### The hook interface this task implements

Task 0.5.4 defines this in `internal/harness` (check the merged code; if it differs, stop and report):

```go
// ToolCallInfo describes a tool call to hooks.
type ToolCallInfo struct {
	RunID   string
	AgentID string
	Step    uint32
	Call    model.ToolCall
	Risk    adlcv1.RiskClass
	Server  string
}

// HookDecision is a hook's answer before a tool runs.
// Decision UNSPECIFIED or ALLOW lets the call continue; DENY stops it.
type HookDecision struct {
	Decision adlcv1.Decision
	Reason   string
}

type Hook interface {
	PreTool(ctx context.Context, info ToolCallInfo) (HookDecision, error)
	PostTool(ctx context.Context, info ToolCallInfo, res toolrouter.Result) error
}
```

### `plugin.proto` (exact content)

```proto
syntax = "proto3";

// Out-of-process plugins. A plugin is a program that serves one of these
// services on the Unix socket named by the ADLC_PLUGIN_SOCKET environment
// variable. Compatibility rules are the same as for events.proto.
package adlc.v1;

import "adlc/v1/events.proto";
import "google/protobuf/duration.proto";

// HookService lets a plugin inspect tool calls before and after they run.
service HookService {
  // PreTool is called before a tool call runs. DECISION_DENY stops it;
  // DECISION_UNSPECIFIED and DECISION_ALLOW let it continue.
  rpc PreTool(PreToolRequest) returns (PreToolResponse);
  // PostTool is called after a tool call finished.
  rpc PostTool(PostToolRequest) returns (PostToolResponse);
}

// ToolCallInfo describes one tool call.
message ToolCallInfo {
  string run_id = 1;
  string agent_id = 2;
  uint32 step = 3;
  ToolCall call = 4;
  RiskClass risk_class = 5;
  string server = 6;
}

message PreToolRequest {
  ToolCallInfo info = 1;
}

message PreToolResponse {
  Decision decision = 1;
  string reason = 2;
}

message PostToolRequest {
  ToolCallInfo info = 1;
  bool is_error = 2;
  bytes output = 3;
  int32 exit_code = 4;
  google.protobuf.Duration duration = 5;
}

message PostToolResponse {}
```

(This exact file passes `buf lint` with the repo's `STANDARD` rules; the service
name must end in `Service`.)

### `internal/plugin` API (exact)

```go
package plugin

// SocketEnv is the environment variable that tells a plugin where to listen.
const SocketEnv = "ADLC_PLUGIN_SOCKET"

var (
	// ErrStartTimeout: the plugin did not accept connections in time.
	ErrStartTimeout = errors.New("plugin: start timeout")
	// ErrExited: the plugin process is not running (before or during a call).
	ErrExited = errors.New("plugin: process exited")
	// ErrClosed: the Process was closed.
	ErrClosed = errors.New("plugin: closed")
)

// Config describes how to start a plugin.
type Config struct {
	Name         string        // used in errors and the socket file name; [a-z0-9-]+
	Command      []string      // argv; Command[0] is the program
	Env          []string      // extra "KEY=VALUE" entries, appended to os.Environ()
	Dir          string        // working directory; "" = current
	StartTimeout time.Duration // 0 = 10s
	CallTimeout  time.Duration // 0 = 5s, per RPC
}

// Process is a running plugin. It implements harness.Hook.
type Process struct { /* unexported fields */ }

// Start launches the plugin and waits until it accepts connections.
func Start(ctx context.Context, cfg Config) (*Process, error)

// PreTool implements harness.Hook.
func (p *Process) PreTool(ctx context.Context, info harness.ToolCallInfo) (harness.HookDecision, error)

// PostTool implements harness.Hook.
func (p *Process) PostTool(ctx context.Context, info harness.ToolCallInfo, res toolrouter.Result) error

// Close stops the plugin (SIGTERM, then SIGKILL after 3s) and removes its
// socket directory. Safe to call more than once.
func (p *Process) Close() error

var _ harness.Hook = (*Process)(nil)
```

### `Start` algorithm

1. Validate: `len(cfg.Command) > 0`, `cfg.Name` matches `^[a-z0-9-]+$`; otherwise return
   `fmt.Errorf("plugin: invalid config: %s", what)`.
2. `dir, err := os.MkdirTemp("", "adlcp-")`; `sock := filepath.Join(dir, cfg.Name+".sock")`.
   If `len(sock) > 100`, remove `dir` and return `fmt.Errorf("plugin %s: socket path too long (%d bytes)", name, len(sock))`
   (Unix socket paths are limited to about 104–108 bytes).
3. `cmd := exec.Command(cfg.Command[0], cfg.Command[1:]...)` — **not** `exec.CommandContext`: the plugin must
   outlive `ctx`, which only bounds start-up. Set `cmd.Dir = cfg.Dir`,
   `cmd.Env = append(append(os.Environ(), SocketEnv+"="+sock), cfg.Env...)`.
   Send both stdout and stderr to a `tailBuffer` (a `sync.Mutex`-guarded buffer keeping the last 8 KiB).
4. `cmd.Start()`. Start a goroutine: `err := cmd.Wait(); p.waitErr = err; close(p.exited)`.
5. Poll every 20 ms until one of:
   - `net.DialTimeout("unix", sock, 100*time.Millisecond)` succeeds → close that test connection, continue to 6;
   - `p.exited` is closed → return `fmt.Errorf("plugin %s: %w before listening: %v; output: %s", name, ErrExited, waitErr, tail)`;
   - `StartTimeout` passed → kill the process, wait for `p.exited`, return
     `fmt.Errorf("plugin %s: %w after %s; output: %s", name, ErrStartTimeout, timeout, tail)`;
   - `ctx.Done()` → kill, wait, return `ctx.Err()` wrapped with the plugin name.
6. `conn, err := grpc.NewClient("unix://"+sock, grpc.WithTransportCredentials(insecure.NewCredentials()))`;
   `p.client = adlcv1.NewHookServiceClient(conn)`.

### Calls (`PreTool`, `PostTool`)

1. If closed → `ErrClosed`. If `p.exited` is closed → `fmt.Errorf("plugin %s: %w", name, ErrExited)`.
2. `cctx, cancel := context.WithTimeout(ctx, CallTimeout)`.
3. Call the RPC with the converted request (`convert.go`).
4. On error: wait up to 200 ms for `p.exited`; if it closed, return `fmt.Errorf("plugin %s: pre_tool: %w", name, ErrExited)`
   (use `post_tool` in PostTool); otherwise return `fmt.Errorf("plugin %s: pre_tool: %w", name, err)`.
5. `PreTool` maps the response: `UNSPECIFIED` → `HookDecision{Decision: DECISION_ALLOW}`; otherwise copy
   `decision` and `reason`. Any value other than `ALLOW`, `DENY` or `UNSPECIFIED` (for example `NEEDS_APPROVAL`)
   → error `plugin <name>: unsupported decision <enum String()>`.

### Conversion (`convert.go`)

```go
func toProtoInfo(info harness.ToolCallInfo) *adlcv1.ToolCallInfo // call: {Id, Name, ArgumentsJson: string(Arguments)}
func toPostToolRequest(info harness.ToolCallInfo, res toolrouter.Result) *adlcv1.PostToolRequest // duration via durationpb.New
```

### `Close`

1. `sync.Once`. Mark closed. `conn.Close()` (ignore its error).
2. If the process is still running: `cmd.Process.Signal(syscall.SIGTERM)`; wait for `p.exited` up to 3 s; then
   `cmd.Process.Kill()` and wait for `p.exited`.
3. `os.RemoveAll(dir)` — only the directory `Start` created with `MkdirTemp`.
4. Return `nil` (a plugin that exited non-zero after SIGTERM is not an error).

## Tests

The helper plugin lives in `plugin_test.go`. It uses the standard "helper process" pattern: the test binary
re-executes itself and runs only `TestHelperPlugin`, which acts as a plugin when an environment variable is set.

```go
func TestHelperPlugin(t *testing.T) {
	mode := os.Getenv("ADLC_TEST_PLUGIN_MODE")
	if mode == "" {
		t.Skip("helper process for other tests")
	}
	// modes: "deny" (PreTool → DENY, reason "denied by helper"), "allow" (PreTool → UNSPECIFIED),
	// "record" (PostTool appends "<tool name>\n" to the file in ADLC_TEST_RECORD),
	// "crash" (PreTool calls os.Exit(3)), "never-listen" (sleep 1h), "exit-early" (print "boom" to stderr, os.Exit(1)),
	// "approval" (PreTool → NEEDS_APPROVAL).
	// Serve adlcv1.HookServiceServer on net.Listen("unix", os.Getenv(SocketEnv)) with grpc.NewServer(); os.Exit(0) when Serve returns.
}

func helper(mode string, extraEnv ...string) Config {
	return Config{
		Name:    "helper",
		Command: []string{os.Args[0], "-test.run=^TestHelperPlugin$"},
		Env:     append([]string{"ADLC_TEST_PLUGIN_MODE=" + mode}, extraEnv...),
	}
}
```

Test functions (each calls `Start`, defers `Close`):
- `TestPreToolDeny` — mode `deny`: decision `DECISION_DENY`, reason `denied by helper`.
- `TestPreToolUnspecifiedMeansAllow` — mode `allow`: decision `DECISION_ALLOW`.
- `TestPreToolUnsupportedDecision` — mode `approval`: error contains `unsupported decision`.
- `TestPostToolIsCalled` — mode `record` with `ADLC_TEST_RECORD=<t.TempDir()>/rec`: after `PostTool` for tool
  `fs__read_file`, the file contains `fs__read_file`.
- `TestStartTimeout` — mode `never-listen`, `StartTimeout: 300*time.Millisecond`: `errors.Is(err, ErrStartTimeout)`, and
  `Start` returns within 2 s.
- `TestExitBeforeListening` — mode `exit-early`: `errors.Is(err, ErrExited)`; error text contains `boom`.
- `TestCrashDuringCall` — mode `crash`: `PreTool` returns an error with `errors.Is(err, ErrExited)`; a second call
  returns `ErrExited` immediately.
- `TestCloseStopsProcess` — after `Close`, the process has exited (internal `p.exited` closed) and the socket
  directory no longer exists; a second `Close` returns nil; `PreTool` after `Close` returns `ErrClosed`.
- `TestCallTimeout` — add mode `slow` (PreTool sleeps 2 s) with `CallTimeout: 200*time.Millisecond`: error returned
  within 1 s, and `errors.Is(err, context.DeadlineExceeded)` or the gRPC status code is `DeadlineExceeded`
  (`status.Code(err) == codes.DeadlineExceeded`).
- `TestInvalidConfig` — empty command and name `Bad Name` are rejected without starting anything.
- `TestConvertToolCallInfo` (in `convert_test.go`) — every field of `ToolCallInfo` arrives in the proto message.

## Pitfalls

- `exec.CommandContext(ctx, ...)` would kill the plugin when the start-up context ends. Use `exec.Command`.
- Do not wait for the socket file alone: it can exist before the server accepts connections. Dial it.
- `cmd.Wait` must be called exactly once (in the goroutine). Never call it in `Close`.
- The helper-process test binary inherits the test's environment; a missing `ADLC_TEST_PLUGIN_MODE` makes
  `TestHelperPlugin` skip, which is what normal test runs need.
- Long `TMPDIR` values (macOS) can exceed the socket path limit; that is why the path length is checked.
- After editing `plugin.proto`, run `make proto`; CI fails if `gen/` is stale.
