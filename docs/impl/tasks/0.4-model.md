### Error (errors.go)

```go
func (e *Error) Error() string
```
Format: `"model: <class> (http <status>): <Err>"`, where `<class>` is the
enum name without the prefix, lower case (`rate_limit`, `model`, `timeout`);
omit ` (http <status>)` when `HTTPStatus == 0`; if `Err == nil` use `"error"`.
Example: `model: rate_limit (http 429): slow down`.
`Unwrap` returns `e.Err`.

`IsRetryable(err)` in this order:
1. `err == nil` → false.
2. `errors.As(err, &e)` with `e *Error` → return `e.Retryable`.
3. otherwise → false (this includes `context.Canceled` and `context.DeadlineExceeded`).

The harness additionally checks `ctx.Err()` before retrying, so a cancelled
run is never retried even if the adapter marked the error retryable.

### Price.Cost (price.go)

```
sum = in*InputPerMTok + out*OutputPerMTok + cr*CacheReadPerMTok + cw*CacheWritePerMTok
cost = (sum + 999_999) / 1_000_000          // integer division: rounds up
```
where `in, out, cr, cw` are the `Usage` fields, each clamped to `>= 0`.
All arithmetic in `int64`. Zero `Price` → cost 0.

### Fake (fake.go)

```go
type Fake struct {
	mu       sync.Mutex
	turns    []FakeTurn
	next     int
	requests []*Request
}

func NewFake(turns ...FakeTurn) *Fake
func (f *Fake) Provider() string { return "fake" }
func (f *Fake) Capabilities() Caps { return Caps{ToolCalling: true} }
func (f *Fake) Generate(ctx context.Context, req *Request) (*Response, error)
func (f *Fake) CountTokens(ctx context.Context, req *Request) (int64, error)
func (f *Fake) Requests() []*Request
func (f *Fake) Remaining() int // turns not yet used
```

`Generate`:
1. If `ctx.Err() != nil` → return `nil, ctx.Err()` (do not record, do not consume a turn).
2. Lock. Append a **deep copy** of `req` to `requests` (copy `Messages`, each
   `Parts` slice, the pointed-to `ToolCall`/`ToolResult`/`Blob`, `Tools`).
3. If `next == len(turns)` → return `nil, fmt.Errorf("%w after %d turns", ErrScriptExhausted, len(turns))`.
4. Take `turns[next]`, `next++`.
5. If `turn.Err != nil` → return `nil, turn.Err`.
6. Return a deep copy of `turn.Response`.

`CountTokens`: deterministic estimate, no turn consumed:
`ceil(total / 4)` where `total` = byte length of `System` + every Text,
every `ToolCall.Arguments`, every `ToolResult.Content`, every `ToolSpec`
(`Name`+`Description`+`InputSchema`). Returns `ctx.Err()` if set.

`Requests()` returns a copy of the slice (same pointers is fine).

### Fake script JSON (fakescript.go)

```go
// ParseFakeScript decodes a fake script. Unknown fields are an error.
func ParseFakeScript(data []byte) ([]FakeTurn, error)
// LoadFakeScript reads the file at path and calls ParseFakeScript.
func LoadFakeScript(path string) ([]FakeTurn, error)
```

Format (the whole file is one object):

```json
{
  "turns": [
    {
      "text": "Let me read the file.",
      "tool_calls": [
        {"id": "t1", "name": "fs__read_file", "arguments": {"path": "README.md"}}
      ],
      "usage": {"input_tokens": 120, "output_tokens": 25}
    },
    {
      "error": {"class": "rate_limit", "http_status": 429, "retryable": true, "message": "slow down"}
    },
    {
      "text": "The README says hello.",
      "finish": "end_turn",
      "usage": {"input_tokens": 180, "output_tokens": 9, "cache_read_tokens": 100}
    }
  ]
}
```

Rules (each violation is an error that names the turn index, e.g.
`model: fake script turn 2: ...`):
- `turns` must have at least one entry.
- A turn has either `error`, or at least one of `text` / `tool_calls`; not both kinds.
- `finish` is one of `end_turn`, `tool_use`, `max_tokens`, `refusal`, `paused`,
  `other`. If omitted: `tool_use` when `tool_calls` is non-empty, else `end_turn`.
  A `refusal` turn may have empty `text`.
- Each tool call needs non-empty `id` and `name`; `name` must match
  `ToolNamePattern`; `arguments` must be a JSON object (default `{}` if omitted).
- `error.class` is one of `model`, `rate_limit`, `timeout`, `internal`; it maps
  to `ERROR_CLASS_<UPPER>`. The turn becomes `FakeTurn{Err: &Error{Class, HTTPStatus, Retryable, Err: errors.New(message)}}`.
- `usage` fields: `input_tokens`, `output_tokens`, `cache_read_tokens`, `cache_write_tokens`, all optional, default 0.
- Response message: `Role: RoleAssistant`, parts in this order: one `TextPart`
  (only if `text` is non-empty), then one `ToolCallPart` per tool call.
  `ProviderFinish` is the `finish` string.

Use `json.NewDecoder(bytes.NewReader(data))` with `DisallowUnknownFields()`
and private structs with `json` tags mirroring the format. Arguments decode
into `json.RawMessage`.

`testdata/hello.json` is exactly the example above.

### Contract tests (package modeltest) — proposed addition to interfaces.md §2.4

```go
package modeltest

// Scenario is one model call and the provider-neutral result an adapter must
// produce for it. Exactly one of Want and WantErr is set.
type Scenario struct {
	Name    string
	Request *model.Request
	Want    *model.Response
	WantErr *model.Error // only Class, HTTPStatus and Retryable are compared
}

// Scenario names. Adapter tests key their canned provider responses by these.
const (
	TextReply           = "text_reply"
	ToolCall            = "tool_call"
	ParallelToolCalls   = "parallel_tool_calls"
	ToolResultRoundTrip = "tool_result_round_trip"
	Refusal             = "refusal"
	MaxTokens           = "max_tokens"
	RateLimited         = "rate_limited"
	ServerError         = "server_error"
	BadRequest          = "bad_request"
)

// Standard returns all scenarios above, in that order.
func Standard() []Scenario

// Run runs every scenario in Standard as a subtest named after it.
// newAdapter must return an adapter whose provider (usually an
// httptest.Server) answers that scenario. Run calls Generate once and checks
// the result with CheckResponse or CheckError.
func Run(t *testing.T, newAdapter func(t *testing.T, sc Scenario) model.Adapter)

// CheckResponse fails t if got differs from want. It ignores ProviderFinish
// and Blob.Data, and compares ToolCall.Arguments as JSON values (key order
// and whitespace do not matter).
func CheckResponse(t testing.TB, got, want *model.Response)

// CheckError fails t unless err is a *model.Error with want's Class,
// HTTPStatus and Retryable.
func CheckError(t testing.TB, err error, want *model.Error)
```

Scenario contents (`Model: "test-model"`, `MaxTokens: 1024`, `System: "You are a test."` in every request):

| Name | Request messages / tools | Want |
|------|--------------------------|------|
| `text_reply` | user "Say hello." | text "Hello!", `END_TURN`, usage in 10 / out 3 |
| `tool_call` | user "Read main.go.", tool `fs__read_file` (schema below) | one call `{ID "call_1", Name "fs__read_file", Arguments {"path":"main.go"}}`, `TOOL_USE`, usage 20/8 |
| `parallel_tool_calls` | user "Read a.go and b.go.", same tool | calls `call_1` (a.go), `call_2` (b.go) in that order, `TOOL_USE`, usage 20/16 |
| `tool_result_round_trip` | user "Read main.go." · assistant [call_1 as in `tool_call`] · user [ToolResult{CallID "call_1", Content "line1\nline2\nline3"}] | text "The file has 3 lines.", `END_TURN`, usage 40/7 |
| `refusal` | user "Do something harmful." | no parts, `REFUSAL`, usage 5/0 |
| `max_tokens` | user "Write a long story." | text "Once upon", `MAX_TOKENS`, usage 6/1024 |
| `rate_limited` | user "Say hello." | `WantErr{RATE_LIMIT, 429, true}` |
| `server_error` | user "Say hello." | `WantErr{MODEL, 500, true}` |
| `bad_request` | user "Say hello." | `WantErr{MODEL, 400, false}` |

Tool schema for `fs__read_file`:
`{"type":"object","properties":{"path":{"type":"string"}},"required":["path"]}`,
description "Read a file."

`modeltest_test.go` runs `Run` with an adapter built from the scenario:
`model.NewFake(model.FakeTurn{Response: sc.Want})` or `{Err: sc.WantErr}`.
This proves the scenarios and the checker are consistent.

## Pitfalls

- `json.RawMessage` is a `[]byte`: deep copies must copy it (`append([]byte(nil), raw...)`).
- `ToolCallPart(c ToolCall)` must store a pointer to a **copy** — taking `&c` of the parameter already is one; do not store a pointer into a caller's slice.
- `Price.Cost`: compute the sum first, then round once. Rounding each term separately gives a different (wrong) total.
- `ParseFakeScript`: `DisallowUnknownFields` only applies to the decoder you call it on; decode the whole document with that one decoder.
- Do not import anything from `internal/harness` or `internal/toolrouter` here; `model` is a leaf package (it may import `gen/go/adlc/v1` only).
