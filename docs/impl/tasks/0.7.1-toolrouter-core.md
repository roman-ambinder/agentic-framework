## Design

Use the declarations in `interfaces.md` §5 exactly. Additional exact details:

```go
package toolrouter

// Package doc comment (in toolrouter.go):
// Package toolrouter lists the tools an agent may call and runs those calls.

var toolNameRE = regexp.MustCompile(model.ToolNamePattern)

// Namespaced returns server + "__" + tool. It does not validate.
func Namespaced(server, tool string) string { return server + "__" + tool }

// ValidateTool checks one Tool. Errors (exact text, %q = the tool name):
//   "toolrouter: tool name %q does not match ^[a-zA-Z0-9_-]{1,64}$"
//   "toolrouter: tool %q has no risk class"
//   "toolrouter: tool %q has no server"
//   "toolrouter: tool %q input schema is not a JSON object"
// An empty InputSchema is allowed and means {"type":"object"}.
func ValidateTool(t Tool) error
```

`ValidateTool` is exported because 0.7.2 uses it too.

**Guarantee for every `Router` implementation** (`interfaces.md §5`): every
tool returned by `Tools()` has passed `ValidateTool`, so its `Risk` is never
`RISK_CLASS_UNSPECIFIED`. The harness relies on this: it only sees
UNSPECIFIED for tools that are not in `Tools()` (unknown tools).

### `ForModel` (file `cap.go`)

```go
const DefaultMaxModelBytes = 16 * 1024

func ForModel(out []byte, max int) (text string, truncated bool)
```

Algorithm (in this order):

1. If `max <= 0`, set `max = DefaultMaxModelBytes`.
2. If `len(out) <= max`: return `strings.ToValidUTF8(string(out), "�"), false`.
3. `cut := max`. While `cut > 0 && !utf8.RuneStart(out[cut])`, `cut--`.
   (This moves the cut back to the start of a UTF-8 character, so no
   character is split.)
4. `text = strings.ToValidUTF8(string(out[:cut]), "�")`.
5. Append `fmt.Sprintf("\n[output truncated: showing %d of %d bytes]", cut, len(out))`.
6. Return `text, true`.

### `Static` (file `static.go`)

```go
type Func func(ctx context.Context, args json.RawMessage) (Result, error)

type StaticTool struct {
	Tool Tool
	Fn   Func
}

type Static struct {
	tools []Tool               // in the order given to NewStatic
	fns   map[string]Func      // key: Tool.Spec.Name
	now   func() time.Time     // time.Now; tests do not need to override it
}

func NewStatic(tools ...StaticTool) (*Static, error)
func (s *Static) Tools() []Tool
func (s *Static) Call(ctx context.Context, call model.ToolCall) (Result, error)
func (s *Static) Close() error // returns nil
```

`NewStatic` rules:
1. For each entry: `ValidateTool(entry.Tool)`; return the first error.
2. If `entry.Fn == nil`: error `toolrouter: tool %q has no function`.
3. If the name was already seen: error `toolrouter: duplicate tool %q`.
4. Store a copy of the `Tool`.

`Tools()` returns a new slice (copy) in `NewStatic` order, so callers cannot
modify the router.

`Call` algorithm:
1. Look up `call.Name`. If missing: return `Result{}, fmt.Errorf("%w: %q", ErrUnknownTool, call.Name)`.
2. If `ctx.Err() != nil`, return `Result{}, ctx.Err()`.
3. `args := call.Arguments`; if `len(args) == 0`, use `json.RawMessage("{}")`.
4. `start := s.now()`; `res, err := fn(ctx, args)`.
5. If `err != nil`: return `Result{}, fmt.Errorf("toolrouter: %s: %w", call.Name, err)`.
6. If `res.Duration == 0`, set `res.Duration = s.now().Sub(start)`.
7. Return `res, nil`.

Remember the rule in interfaces §5: a tool that ran and failed returns
`Result{IsError: true}` with `nil` error. A `Func` returning an error means
the call could not be made.

## Pitfalls

- `json.RawMessage` is a slice: never use `Tool` as a map key (it will not compile). Key maps by `Tool.Spec.Name`.
- `utf8.RuneStart` takes a byte, and `out[cut]` is only valid when `cut < len(out)` — that is guaranteed in step 3 because `len(out) > max`.
- Do not trim or reformat tool output other than the cap; the model must see what the tool printed.
- Return copies from `Tools()`; the harness may sort or filter the slice.
