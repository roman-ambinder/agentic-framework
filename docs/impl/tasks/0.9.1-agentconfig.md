# 0.9.1 — agent.yaml schema and loader

Size: M · Depends on: 0.4, 0.6 · Branch: `task/0.9.1-agentconfig` · PR title: `0.9.1: agent.yaml schema, loader and validation`

## Goal

Package `internal/agentconfig` reads an agent definition from YAML, rejects
unknown fields, validates every value and reports **all** problems at once
with their field paths, and returns typed values (`model.Price`,
`*adlcv1.Budget`, `*policy.Static`, tool servers with parsed risk classes).
Turning these into a `harness.Config` and MCP server configs is task 0.9.2.

## Design

### File format (this exact example goes into `testdata/full.yaml`)

```yaml
# Agent definition. Unknown fields are errors.
name: hello                       # required; ^[a-z][a-z0-9-]{0,31}$
version: 1                        # required; >= 1. Agent id is "<name>@<version>"
model:
  provider: anthropic             # required; one of: fake, anthropic, openai
  name: example-model-id          # required unless provider is fake (default "fake-model");
                                  # may be exactly "${VAR}": replaced by the environment variable VAR
  max_tokens: 4096                # optional; default 4096; 1..1000000
  effort: high                    # optional; "", low, medium, high, xhigh, max
  pricing:                        # optional; USD per million tokens, decimal strings
    input_per_mtok: "1.50"
    output_per_mtok: "7.50"
    cache_read_per_mtok: "0.15"
    cache_write_per_mtok: "1.875"
system: |
  You are a careful assistant. Use the tools to answer.
# system_file: prompt.md          # optional; instead of system: read the prompt from this file,
                                  # relative to the agent file's directory. Not both.
max_tool_output_bytes: 16384      # optional; default 16384; 1..10485760
tools:                            # optional
  - server: fs                    # required; ^[a-z][a-z0-9_]{0,15}$, no "__", unique
    command: ["adlc", "tool", "fs", "--root", "./workspace"]  # required, non-empty
    env: {}                       # optional
    risk:                         # optional; tool name -> risk class
      read_file: read
      list_dir: read
      write_file: write_local
    default_risk: ""              # optional; risk class for unlisted tools
budget:                           # optional; 0 or missing = no limit
  max_steps: 20
  max_tokens: 200000
  max_wall_clock: 10m             # Go duration string
  max_usd: "1.00"                 # decimal string
  max_tool_calls: 50
policy:
  default: deny                   # required; allow, deny, needs_approval
  rules:                          # optional; first match wins
    - id: reads                   # required, unique
      risk: read                  # optional; "" = any risk
      tool: ""                    # optional; namespaced tool name; "" = any tool
      decision: allow             # required
    - id: local-writes
      risk: write_local
      decision: needs_approval
```

(The prices above are placeholders for the example, not real prices.)

### Go types (`agentconfig.go`)

```go
package agentconfig

type Agent struct {
	Name               string       `yaml:"name"`
	Version            int          `yaml:"version"`
	Model              Model        `yaml:"model"`
	System             string       `yaml:"system"`
	SystemFile         string       `yaml:"system_file"`
	MaxToolOutputBytes int          `yaml:"max_tool_output_bytes"`
	Tools              []ToolServer `yaml:"tools"`
	Budget             Budget       `yaml:"budget"`
	Policy             Policy       `yaml:"policy"`

	// Dir is the directory of the file Load read ("" for Parse). Not in YAML.
	Dir string `yaml:"-"`
}

type Model struct {
	Provider  string  `yaml:"provider"`
	Name      string  `yaml:"name"`
	MaxTokens int     `yaml:"max_tokens"`
	Effort    string  `yaml:"effort"`
	Pricing   Pricing `yaml:"pricing"`
}

type Pricing struct {
	InputPerMTok      string `yaml:"input_per_mtok"`
	OutputPerMTok     string `yaml:"output_per_mtok"`
	CacheReadPerMTok  string `yaml:"cache_read_per_mtok"`
	CacheWritePerMTok string `yaml:"cache_write_per_mtok"`
}

type ToolServer struct {
	Server      string            `yaml:"server"`
	Command     []string          `yaml:"command"`
	Env         map[string]string `yaml:"env"`
	Risk        map[string]string `yaml:"risk"`
	DefaultRisk string            `yaml:"default_risk"`
}

type Budget struct {
	MaxSteps     uint32 `yaml:"max_steps"`
	MaxTokens    int64  `yaml:"max_tokens"`
	MaxWallClock string `yaml:"max_wall_clock"`
	MaxUSD       string `yaml:"max_usd"`
	MaxToolCalls uint32 `yaml:"max_tool_calls"`
}

type Policy struct {
	Default string `yaml:"default"`
	Rules   []Rule `yaml:"rules"`
}

type Rule struct {
	ID       string `yaml:"id"`
	Risk     string `yaml:"risk"`
	Tool     string `yaml:"tool"`
	Decision string `yaml:"decision"`
}

// Load reads, decodes (strict), applies defaults and validates the file.
func Load(path string) (*Agent, error)

// Parse does the same for bytes; Dir stays "".
func Parse(data []byte) (*Agent, error)

// Defaults used when a field is empty or zero.
const (
	DefaultMaxTokens          = 4096
	DefaultMaxToolOutputBytes = 16 * 1024
	DefaultFakeModel          = "fake-model"
)
```

`Load` algorithm:
1. `data, err := os.ReadFile(path)`; error → `agentconfig: %w`.
2. `abs, _ := filepath.Abs(path)`; `a, err := parse(data, filepath.Dir(abs))`;
   error → `fmt.Errorf("agentconfig: %s: %w", path, err)`.
3. Return `a` (its `Dir` is set by `parse`).

`Parse(data)` is `parse(data, "")`. `parse(data, dir)` algorithm:
1. `var a Agent`; `yaml.UnmarshalWithOptions(data, &a, yaml.Strict())`. On error return
   `fmt.Errorf("decode: %s", yaml.FormatError(err, false, true))`. Set `a.Dir = dir`.
2. `a.applyDefaults()`: `MaxTokens` 0 → 4096; `MaxToolOutputBytes` 0 → 16384;
   provider `fake` and `Name` "" → `"fake-model"`.
3. `a.resolve()` — collects problems in the same collector as `Validate` and
   returns them joined (stop if non-nil):
   - **Environment in `model.name`:** if `Name` matches `^\$\{([A-Z_][A-Z0-9_]*)\}$`,
     `v, ok := os.LookupEnv(name)`; `!ok || v == ""` → problem
     `model.name: environment variable <VAR> is not set`; else `Name = v`.
     No other `$` forms are expanded (a name with `$` that does not match is used as is).
   - **`system_file`:** if `SystemFile != ""`: if `System != ""` → problem
     `system_file: cannot be used together with system`; else read
     `filepath.Join(dir, SystemFile)` (or `SystemFile` itself when it is absolute);
     error → problem `system_file: <error>`; empty file → problem `system_file: file is empty`;
     else `System = string(content)`.
4. `if err := a.Validate(); err != nil { return nil, err }`.
5. Return `&a`.

Model ids are kept out of the repository: committed agent files use
`name: ${ADLC_ANTHROPIC_MODEL}` / `${ADLC_OPENAI_MODEL}`, and live tests read
the same variables.

### Validation (`validate.go`)

```go
// Validate checks every field and returns all problems joined with
// errors.Join. Each problem is an error whose text is "<path>: <message>".
func (a *Agent) Validate() error
```

Use a small collector:
```go
type problems []error
func (p *problems) add(path, format string, args ...any) { *p = append(*p, fmt.Errorf("%s: "+format, append([]any{path}, args...)...)) }
```

Checks, in this order (exact messages; `%q` = the bad value):

| Path | Rule | Message |
|------|------|---------|
| `name` | matches `^[a-z][a-z0-9-]{0,31}$` | `must match ^[a-z][a-z0-9-]{0,31}$, got %q` |
| `version` | `>= 1` | `must be >= 1` |
| `model.provider` | `fake`, `anthropic` or `openai` | `must be one of fake, anthropic, openai, got %q` |
| `model.name` | non-empty | `is required` |
| `model.max_tokens` | 1..1000000 | `must be between 1 and 1000000` |
| `model.effort` | "", low, medium, high, xhigh, max | `must be one of low, medium, high, xhigh, max, got %q` |
| `model.pricing.<field>` | `ParseMicroUSD` ok (empty = 0) | `%q is not a decimal amount with at most 6 decimals` |
| `max_tool_output_bytes` | 1..10485760 | `must be between 1 and 10485760` |
| `tools[i].server` | matches `^[a-z][a-z0-9_]{0,15}$` and no `__` | `must match ^[a-z][a-z0-9_]{0,15}$ without "__", got %q` |
| `tools[i].server` | unique | `duplicate server %q` |
| `tools[i].command` | non-empty, and `command[0] != ""` | `is required` |
| `tools[i].risk.<tool>` | `policy.ParseRiskClass` ok | `unknown risk class %q` |
| `tools[i].default_risk` | "" or `policy.ParseRiskClass` ok | `unknown risk class %q` |
| `budget.max_wall_clock` | "" or `time.ParseDuration` ok and > 0 | `%q is not a positive duration` |
| `budget.max_usd` | "" or `ParseMicroUSD` ok | `%q is not a decimal amount with at most 6 decimals` |
| `policy.default` | `policy.ParseDecision` ok | `must be one of allow, deny, needs_approval, got %q` |
| `policy.rules[i].id` | non-empty, unique, not `default` (reserved by `policy.NewStatic`) | `is required` / `duplicate rule id %q` / `rule id "default" is reserved` |
| `policy.rules[i].risk` | "" or `ParseRiskClass` ok | `unknown risk class %q` |
| `policy.rules[i].decision` | `ParseDecision` ok | `must be one of allow, deny, needs_approval, got %q` |

For the `risk` map, iterate keys in sorted order so messages are stable.

### Money (`money.go`)

```go
// ParseMicroUSD parses a decimal USD amount ("1", "1.5", "0.000001") into
// micro-USD without floating point. "" -> 0. Max 6 decimals, no sign, no
// exponent, at most 9 digits before the point.
func ParseMicroUSD(s string) (int64, error)
```
Algorithm: `""` → `0, nil`. Match `^(0|[1-9][0-9]{0,8})(\.([0-9]{1,6}))?$`;
no match → `fmt.Errorf("agentconfig: %q is not a decimal amount with at most 6 decimals", s)`.
`whole, _ := strconv.ParseInt(m[1], 10, 64)`; `frac := m[3] + strings.Repeat("0", 6-len(m[3]))`;
`f, _ := strconv.ParseInt(frac, 10, 64)` (frac "" → "000000");
return `whole*1_000_000 + f`.

### Conversions (`convert.go`) — call only after `Validate` succeeded

```go
func (a *Agent) AgentID() string               // fmt.Sprintf("%s@%d", a.Name, a.Version)
func (a *Agent) Price() model.Price            // ParseMicroUSD of each pricing field
func (a *Agent) BudgetProto() *adlcv1.Budget   // nil if every budget field is zero/empty
func (a *Agent) PolicyEngine() *policy.Static  // policy.NewStatic(rules in file order, default); Risk "" -> UNSPECIFIED
func (a *Agent) ToolServers() []ParsedToolServer

type ParsedToolServer struct {
	Name        string
	Command     []string
	Env         map[string]string
	Dir         string // = a.Dir (commands run in the agent file's directory)
	Risk        map[string]adlcv1.RiskClass
	DefaultRisk adlcv1.RiskClass
}
```
`BudgetProto`: `MaxWallClock` → `durationpb.New(d)`; `MaxUsd` → `MaxUsdMicros`.
Errors are impossible after `Validate`; ignore them (use `_`).

## Pitfalls

- Never parse money with `strconv.ParseFloat`: `0.1` is not exact in binary floating point.
- `yaml.Strict()` is what rejects unknown fields; without it typos are silently ignored.
- Collect problems; do not stop at the first one. Tests check that several are reported together.
- Map iteration order is random: sort keys before validating the `risk` and `env` maps.
- `Dir` must be absolute so later code does not depend on the current directory.
