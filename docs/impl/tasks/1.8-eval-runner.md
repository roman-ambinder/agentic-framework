# 1.8 — Eval runner

Size: M · Depends on: E.3, 1.5, 0.9.2 · Branch: `task/1.8-eval-runner` · PR title: `1.8: adlc eval runs an agent on each seeded bug in a sandbox`

## Goal

After this task, `adlc eval evals/suites/go-bugs --agents <agent.yaml>[,<agent.yaml>…]`
runs every selected bug once per agent file: it prepares the buggy workspace,
starts a sandbox, runs the harness with the issue text as the task, copies the
workspace back out, runs the hidden tests in a **fresh** sandbox, and writes a
JSON report plus a short table. Each agent file names its own provider and
model, so comparing providers means passing one file per provider. Grading
beyond "hidden tests pass" is task 1.9.

**No protobuf schema change in M1.** Eval results live in the JSON report;
each result links to its harness run by `run_id`, whose events are in the
normal event log.

## Design

### Types (`internal/evals/runner.go`)

```go
// AgentRun is what RunAgent needs to run one agent on one bug.
type AgentRun struct {
	RunID   string
	Agent   *agentconfig.Agent
	Bug     Bug
	Sandbox sandbox.Sandbox
	Handle  sandbox.Handle // sandbox whose /workspace holds the buggy repo
}

// Runner runs bugs through agents.
type Runner struct {
	Suite   *Suite
	Sandbox sandbox.Sandbox
	Log     harness.Log           // where RunAgent's events go; Runner only reads
	Image   string                // container image; "" = DefaultImage
	WorkDir string                // host dir for workspaces; required
	// RunAgent runs the harness for one AgentRun and returns the final state.
	// The CLI wires the real harness; tests pass a fake.
	RunAgent func(ctx context.Context, ar AgentRun) (*eventlog.RunState, error)
	Now      func() time.Time      // default time.Now
	Stdout   io.Writer             // progress lines; nil = io.Discard
}

// DefaultImage is used when Runner.Image is empty.
const DefaultImage = "golang:1.26"

// Result is the outcome of one bug × agent.
type Result struct {
	BugID        string              `json:"bug_id"`
	Difficulty   Difficulty          `json:"difficulty"`
	Agent        string              `json:"agent"`    // agent id, e.g. "coder-anthropic@1"
	Provider     string              `json:"provider"` // from the agent file
	RunID        string              `json:"run_id"`
	StopReason   string              `json:"stop_reason"` // adlcv1.StopReason name, e.g. "STOP_REASON_COMPLETED"; "" if the run never started
	Hidden       TestOutcome         `json:"hidden"`
	ChangedFiles []string            `json:"changed_files"` // relative paths, sorted
	Error        string              `json:"error,omitempty"` // infrastructure failure; Hidden is then empty
	DurationMS   int64               `json:"duration_ms"`
	State        *eventlog.RunState  `json:"-"`               // for graders (task 1.9)
}

// Solved reports Hidden.AllPassed() && Error == "". Task 1.9 replaces this
// definition with the grader's.
func (r Result) Solved() bool

func (r *Runner) RunOne(ctx context.Context, bug Bug, agent *agentconfig.Agent) Result
func (r *Runner) RunAll(ctx context.Context, bugs []Bug, agents []*agentconfig.Agent) ([]Result, error)
```

`RunOne` never returns an error: problems go into `Result.Error`, so one broken
bug does not stop the suite. `RunAll` returns an error only if `ctx` is
cancelled (it then returns the results so far and `ctx.Err()`).

From the agent file the runner needs three things: the agent id
(`a.AgentID()`, task 0.9.1) for `Result.Agent`, the provider name
(`a.Model.Provider`) for `Result.Provider`, and the `harness.Config`,
`model.Adapter` and `policy.Client`, built by task 0.9.2's helpers
(`harnessConfig`, `buildModel`, `a.PolicyEngine()`; see "Real RunAgent wiring").

### Run ID

`fmt.Sprintf("eval-%s-%s-%s", bug.ID, provider, now.UTC().Format("20060102T150405.000"))`
with `.` replaced by `-`. Must be unique per result.

### Algorithm of `RunOne` (numbered; implement in this order)

1. `start := now()`; fill `Result{BugID, Difficulty, Agent, Provider, RunID}`.
2. `base := filepath.Join(r.WorkDir, runID)`; `ws := filepath.Join(base, "before")`.
3. `r.Suite.PrepareWorkspace(ctx, bug, ws, PrepareOptions{})` — bug applied, no fix, no hidden test.
   On error: `Result.Error = "prepare workspace: " + err.Error()`, return.
4. `spec := sandbox.Spec{RunID: runID, Image: image, WorkspaceDir: ws, CPUs: 2, MemoryBytes: 4 << 30, Network: false, Env: goEnv}` where
   `goEnv = map[string]string{"GOTOOLCHAIN": "local", "GOFLAGS": "-mod=mod", "GOWORK": "off", "GOCACHE": "/tmp/gocache", "HOME": "/tmp", "CGO_ENABLED": "0"}`.
5. `h, err := r.Sandbox.Create(ctx, spec)`; on error `Result.Error = "create sandbox: " + …`, return.
   `defer r.Sandbox.Destroy(context.WithoutCancel(ctx), h)` (ignore its error but log it to Stdout).
6. `state, err := r.RunAgent(ctx, AgentRun{RunID, agent, bug, r.Sandbox, h})`.
   If `state != nil`, set `Result.State = state` and `Result.StopReason = state.StopReason.String()`.
   If `err != nil`: `Result.Error = "run agent: " + err.Error()`, return.
   A run that ended with `BUDGET_EXHAUSTED` or `ERROR` is **not** an infrastructure error: continue and grade it.
7. `tarData, err := r.Sandbox.CopyOut(ctx, h, sandbox.WorkspacePath)`; on error `"copy out: …"`, return.
8. `after := filepath.Join(base, "after")`; `extractTar(tarData, after, "workspace")`; on error `"extract: …"`, return.
9. Changed files: in `after`, run `git add -A` then `git diff --cached --name-only HEAD`
   (same `-c` flags and env as E.3's git helper). Split lines, drop empty, sort → `ChangedFiles`.
   The agent may have broken or deleted `.git`. If either git command fails, leave `ChangedFiles` nil,
   print `<bug-id> <provider> git diff failed: <err>` to `Stdout`, and continue — this does not fail the result.
10. Write `bug.HiddenTest` to `filepath.Join(after, HiddenTestPath(bug))` (create parent dirs; overwrite).
11. Fresh sandbox: `spec2 := spec` with `RunID: runID + "-grade"`, `WorkspaceDir: after`. Create, defer Destroy.
12. `res, err := r.Sandbox.Exec(ctx, h2, HiddenTestArgs(bug), bug.Timeout)`; on error `"run hidden tests: …"`, return.
13. `Result.Hidden = ParseTestOutput(bug, append(res.Stdout, res.Stderr...), res.ExitCode, res.TimedOut)`.
14. `Result.DurationMS = now().Sub(start).Milliseconds()`; print one progress line to `Stdout`:
    `<bug-id> <provider> <solved|failed|error> <stop reason> <seconds>s`; return.

`RunAll`: for each bug (in the given order), for each agent (in the given
order): check `ctx.Err()` first; then `RunOne`. Sequential — no goroutines in M1.

### `extractTar(data []byte, dest, stripDir string) error` (`tarx.go`)

Read entries with `archive/tar`. For each entry name: clean it with
`path.Clean`; it must equal `stripDir` or start with `stripDir + "/"`, else
error `evals: unexpected tar entry %q`; remove that prefix; skip the root
itself. Reject absolute paths and any name containing `..` after cleaning
(`evals: unsafe tar entry %q`). Create directories (`0o755`) and regular files
(mode from the header, masked with `0o777`); skip symlinks and other types.

### Report (`report.go`)

```go
type Report struct {
	Suite      string    `json:"suite"`
	StartedAt  time.Time `json:"started_at"`
	FinishedAt time.Time `json:"finished_at"`
	Results    []Result  `json:"results"`
}

func WriteReport(path string, rep Report) error // JSON, 2-space indent, trailing newline
func PrintTable(w io.Writer, results []Result)  // see format below
```

`PrintTable` prints (tab-aligned with `text/tabwriter`, minwidth 0, tabwidth 8, padding 2):

```
BUG                     PROVIDER   RESULT  STOP                 SECONDS
stock-negative-reserve  anthropic  solved  COMPLETED            84
...
anthropic: 6/10 solved
openai: 5/10 solved
```

`RESULT` is `solved`, `failed` or `error`. `STOP` is the stop reason without
the `STOP_REASON_` prefix. The per-provider lines are sorted by provider name.

### CLI (`internal/cli/eval.go`)

```
adlc eval SUITE_DIR --agents FILE[,FILE...] [--bugs ID[,ID...]] [--db PATH] [--out PATH] [--workdir DIR] [--image IMAGE] [--keep-workspaces]
```

| Flag | Default | Meaning |
|------|---------|---------|
| `--agents` | (required) | agent files; one result per bug per file |
| `--bugs` | all | only these bug ids; an unknown id is an error `unknown bug "<id>"` |
| `--db` | `.adlc/events.db` | event log (create the dir) |
| `--out` | `evals/results/<suite>-<UTC yyyymmdd-hhmmss>.json` | report path |
| `--workdir` | a new `os.MkdirTemp("", "adlc-eval-")` | host workspaces |
| `--image` | `golang:1.26` | sandbox image |
| `--keep-workspaces` | false | keep `--workdir` after the run (default: remove it at the end if it was created by this command) |

`RunE` steps: load suite (`evals.LoadSuite`); load each agent file
(`agentconfig.Load`); select bugs; open the event log (`eventlog.Open`); create
the Docker sandbox (`docker.New(ctx)`; on error print
`Docker is not available: <err>` and return it); build `Runner` with
`RunAgent` = the real wiring below; `RunAll`; `WriteReport`; `PrintTable` to
stdout; print `report: <path>`. Exit code 0 even if bugs failed (failures are
results, not errors); non-zero only on errors.

Real `RunAgent` wiring (in `eval.go`):
1. Reuse the helpers task 0.9.2 put in `internal/cli/wiring.go` — no copy-paste:
   `m, err := buildModel(a, "")` (fake agents are not supported by `adlc eval`: if
   `a.Model.Provider == "fake"` return `errors.New("eval: provider fake is not supported")`),
   `cfg := harnessConfig(a, ar.RunID, ar.Bug.Issue)`, `p := a.PolicyEngine()`.
   (Do not use `buildRun`: it starts the agent file's own MCP tool servers; eval agents use the sandbox tools.)
2. Tools: `tools, err := sandboxset.NewRouter(ctx, sandboxtool.Options{Sandbox: ar.Sandbox, Handle: ar.Handle})`
   (task 1.5, `interfaces.md §8`); `defer tools.Close()`.
3. `harness.Run(ctx, cfg, harness.Deps{Log: store, Model: m, Tools: tools, Policy: p})`.

## Out of scope

- Graders other than hidden tests, pass@1 per difficulty, cost/step metrics (task 1.9).
- Running bugs in parallel.
- New event kinds or any `.proto` change.
- Retrying a failed bug.

## Pitfalls

- The agent's workspace must never contain `hidden_test.go`, `fix.patch` or the suite directory. Only `PrepareWorkspace(… PrepareOptions{})` output goes into the first sandbox.
- Grade in a **fresh** sandbox from the copied-out files, not in the agent's sandbox: the agent may have left processes or changed the environment.
- `docker cp` tar entries are named `workspace/...` (the base name of the copied path), not `/workspace/...`.
- Defers that call `Destroy` must use `context.WithoutCancel(ctx)`, or a cancelled run leaks containers.
- `go test -run` matching no tests passes silently; that is why `ParseTestOutput` (E.3) requires a PASS line per test — do not replace it with an exit-code check.
- The `golang:1.26` image is large; the first live run pulls it and takes minutes.
