# 0.9.2 — `adlc run` command

Size: M · Depends on: 0.5.4, 0.5b, 0.8, 0.9.1 · Branch: `task/0.9.2-cli-run` · PR title: `0.9.2: adlc run command and hello example`

## Goal

`adlc run AGENT.yaml --task "..."` loads an agent definition, opens the event
log, starts the agent's MCP tool servers, picks the model (scripted fake or
Anthropic), runs the harness, prints a fixed-format summary and exits with a
code that says how the run ended. `examples/hello.yaml` plus a fake-model
script is a runnable demo, and an end-to-end test runs it.

## Design

### Command line

```
adlc run AGENT_YAML --task TEXT [--db PATH] [--fake-script PATH] [--run-id ID] [--model-name NAME]
```

| Flag | Default | Meaning |
|------|---------|---------|
| `--task` | — (required, `MarkFlagRequired`) | first user message |
| `--db` | `.adlc/events.db` | event log file; parent dir is created (`os.MkdirAll(dir, 0o755)`) |
| `--fake-script` | `""` | fake model script; required when `model.provider` is `fake`, an error otherwise |
| `--run-id` | generated | must match `^[A-Za-z0-9._-]{1,64}$` |
| `--model-name` | `""` | overrides `model.name` from the file |

`Args: cobra.ExactArgs(1)`.

### Exit codes (`exit.go`)

```go
// exitError makes Execute return code without (if err is nil) printing "Error:".
type exitError struct {
	code int
	err  error
}
func (e *exitError) Error() string // err.Error() or fmt.Sprintf("exit code %d", code)
func (e *exitError) Unwrap() error
```

| Code | When |
|------|------|
| 0 | run ended with `STOP_REASON_COMPLETED` |
| 2 | run ended with any other stop reason (summary is still printed) |
| 1 | anything that prevented or broke the run: bad flags, invalid config, event log error, tool server failed to start, `harness.Run` returned an error |

Change `Execute` in `root.go`: after `root.Execute()` returns `err != nil`:
```go
var ee *exitError
if errors.As(err, &ee) {
	if ee.err != nil { root.PrintErrln("Error:", ee.err) }
	return ee.code
}
root.PrintErrln("Error:", err)
return 1
```

### Run id (`runid.go`)

```go
// newRunID returns "run-<UTC time as 20060102T150405Z>-<6 lowercase hex chars>".
func newRunID(now time.Time, random io.Reader) (string, error) // reads 3 bytes from random
func validRunID(s string) bool                                 // ^[A-Za-z0-9._-]{1,64}$
```
Production code passes `time.Now()` and `crypto/rand.Reader`.

### `runAgent` algorithm (`run.go`)

```go
type runOptions struct {
	agentPath, task, db, fakeScript, runID, modelName string
}
func runAgent(ctx context.Context, o runOptions, stdout io.Writer) error
```

1. `a, err := agentconfig.Load(o.agentPath)` → on error `&exitError{1, err}`.
2. If `o.modelName != ""`, set `a.Model.Name = o.modelName`.
3. Run id: if `o.runID == ""`, `newRunID(time.Now(), rand.Reader)`; else if
   `!validRunID(o.runID)` → `&exitError{1, fmt.Errorf("run: invalid --run-id %q", o.runID)}`.
4. `os.MkdirAll(filepath.Dir(o.db), 0o755)`; `store, err := eventlog.Open(ctx, o.db)`; `defer store.Close()`. Errors → code 1.
5. `cfg, deps, cleanup, err := buildRun(ctx, a, o, runID, store)` → error → code 1; `defer cleanup()`.
6. `state, err := harness.Run(ctx, cfg, deps)` → error → code 1.
7. `printSummary(stdout, state)`.
8. If `state.StopReason == adlcv1.StopReason_STOP_REASON_COMPLETED` return nil; else return `&exitError{code: 2}`.

The command's `RunE` wraps `cmd.Context()` with
`signal.NotifyContext(ctx, os.Interrupt, syscall.SIGTERM)` and passes it to
`runAgent` (Ctrl-C ends the run as `CANCELLED`, exit code 2).

### Wiring (`wiring.go`)

`buildRun` is the one place that turns an agent file into a runnable harness
setup. `adlc run` uses it now; `adlc resume` (task 1.7) reuses it unchanged,
and `adlc eval` (task 1.8) reuses `buildModel`, `harnessConfig` and
`a.PolicyEngine()` (it supplies its own sandbox tool router).

```go
// buildRun builds the harness config and dependencies for agent a.
// cleanup closes the tool router; call it once after the run (safe if nil error).
func buildRun(ctx context.Context, a *agentconfig.Agent, o runOptions, runID string, log harness.Log) (cfg harness.Config, deps harness.Deps, cleanup func() error, err error)
```
Algorithm:
1. `m, err := buildModel(a, o.fakeScript)` → return the error.
2. `servers, err := toServerConfigs(a.ToolServers())` → return the error.
3. Tools: if `len(servers) == 0`, `router, err := toolrouter.NewStatic()` (no tools); else
   `router, err := mcprouter.Start(ctx, servers)`, error → `fmt.Errorf("run: start tools: %w", err)`.
4. `cfg = harnessConfig(a, runID, o.task)`.
5. `deps = harness.Deps{Log: log, Model: m, Tools: router, Policy: a.PolicyEngine()}` (leave `Now`/`Sleep` nil = defaults).
6. Return `cfg, deps, router.Close, nil`.

```go
// buildModel picks the adapter from a.Model.Provider.
func buildModel(a *agentconfig.Agent, fakeScript string) (model.Adapter, error)
```
- `fake`: if `fakeScript == ""` → `errors.New("run: provider fake needs --fake-script")`;
  `turns, err := model.LoadFakeScript(fakeScript)`; return `model.NewFake(turns...)`.
- `anthropic`: if `fakeScript != ""` → `errors.New("run: --fake-script only works with provider fake")`;
  return `anthropic.New(anthropic.Options{})` (key from `ANTHROPIC_API_KEY`).
- `openai`: `errors.New("run: provider openai is not wired yet (task 1.2)")` — task 1.2 replaces this case.
- anything else → `fmt.Errorf("run: unsupported provider %q", p)` (cannot happen after validation).

```go
// resolveCommand replaces a leading "adlc" with this executable's path, so
// built-in tool servers run from the same binary.
func resolveCommand(cmd []string) ([]string, error) // uses os.Executable(); copies the slice

func toServerConfigs(in []agentconfig.ParsedToolServer) ([]mcprouter.ServerConfig, error)
// one ServerConfig per entry: Name, Command (resolved), Env, Dir, Risk, DefaultRisk

func harnessConfig(a *agentconfig.Agent, runID, task string) harness.Config
// RunID: runID, AgentID and AgentVersion: a.AgentID(), Task: task, System: a.System,
// Model: a.Model.Name, MaxTokens: a.Model.MaxTokens, Effort: a.Model.Effort,
// Budget: a.BudgetProto(), Price: a.Price(), MaxToolOutputBytes: a.MaxToolOutputBytes.
// Retry and Hooks are left zero (harness defaults).
```

### Summary (`summary.go`) — exact format

```
run:     <run id>
agent:   <agent id>
stop:    <stop name>
detail:  <stop detail>                 (only if non-empty)
steps:   <Step>  tool calls: <ToolCalls>  errors: <Errors>
tokens:  in <in>  out <out>  cache read <cr>  cache write <cw>
cost:    $<formatUSD(USDMicros)>
result:  <Result>                      (only if non-empty)
```
Each line ends with `"\n"`. Labels are padded to 9 characters as shown
(`fmt.Fprintf(w, "%-9s%s\n", "run:", id)`). For the `steps:` and `tokens:`
lines use `fmt.Fprintf(w, "%-9s%d  tool calls: %d  errors: %d\n", "steps:", ...)`
and `fmt.Fprintf(w, "%-9sin %d  out %d  cache read %d  cache write %d\n", "tokens:", ...)`.

```go
func stopName(r adlcv1.StopReason) string // strings.ToLower(strings.TrimPrefix(r.String(), "STOP_REASON_")): "completed", "budget_exhausted", ...
func formatUSD(micros int64) string       // fmt.Sprintf("%d.%06d", micros/1_000_000, micros%1_000_000): 1234567 -> "1.234567"
```

### Example files

`examples/workspace/greeting.txt` — exactly `hello, world` followed by one newline.

`examples/hello.yaml`:
```yaml
name: hello
version: 1
model:
  provider: fake
system: |
  You answer questions about the files in the workspace. Use the fs tools.
tools:
  - server: fs
    command: ["adlc", "tool", "fs", "--root", "./workspace"]
    risk:
      read_file: read
      list_dir: read
      write_file: write_local
budget:
  max_steps: 5
  max_tool_calls: 5
  max_wall_clock: 1m
policy:
  default: deny
  rules:
    - id: reads
      risk: read
      decision: allow
```

`examples/hello-anthropic.yaml` — same, but
`model: {provider: anthropic, name: "${ADLC_ANTHROPIC_MODEL}", max_tokens: 2048}`
and `budget.max_usd: "0.10"`. Set `ADLC_ANTHROPIC_MODEL` in your shell (task 0.9.1
expands it), or pass `--model-name`, which replaces the name after loading.
Loading the file fails if the variable is unset and no `--model-name` is
given; to allow `--model-name` alone, `runAgent` sets the variable for the
load when it is unset: if `o.modelName != ""` and `os.Getenv("ADLC_ANTHROPIC_MODEL") == ""`,
call `os.Setenv("ADLC_ANTHROPIC_MODEL", o.modelName)` before `agentconfig.Load`.
(Only the variables `ADLC_ANTHROPIC_MODEL` and `ADLC_OPENAI_MODEL` are handled this way.)

`examples/hello.fake.json` — two scripted turns, written in the fake script
format defined in brief 0.4 (`model.LoadFakeScript`):
1. text `I'll read the file.`, one tool call `{id: "call_1", name: "fs__read_file", arguments: {"path": "greeting.txt"}}`, finish `tool_use`, usage in 50 / out 20.
2. text `The file says: hello, world`, no tool calls, finish `end_turn`, usage in 90 / out 12.

The file is exactly this (format: brief 0.4, "Fake script JSON"):
```json
{
  "turns": [
    {"text": "I'll read the file.",
     "tool_calls": [{"id": "call_1", "name": "fs__read_file", "arguments": {"path": "greeting.txt"}}],
     "finish": "tool_use", "usage": {"input_tokens": 50, "output_tokens": 20}},
    {"text": "The file says: hello, world",
     "finish": "end_turn", "usage": {"input_tokens": 90, "output_tokens": 12}}
  ]
}
```

### How the end-to-end test runs the fs server

The agent config starts `adlc tool fs`. In tests, `os.Executable()` is the
test binary, so `resolveCommand` points at it. The test binary acts as the
CLI when `ADLC_RUN_AS_CLI=1` (the `TestMain` branch added by task 0.8; if it
is missing, add it):

```go
func TestMain(m *testing.M) {
	if os.Getenv("ADLC_RUN_AS_CLI") == "1" {
		os.Exit(Execute(os.Args[1:], os.Stdout, os.Stderr))
	}
	os.Exit(m.Run())
}
```

The test's agent YAML sets `env: {ADLC_RUN_AS_CLI: "1"}` on the `fs` server.
This avoids building the binary in tests and also tests `resolveCommand`.

## Out of scope

- `adlc trace` (task 0.10), `adlc cost` (task 1.11), `adlc resume` (task 1.7).
- Provider `openai` (task 1.2 adds a case to `buildModel`).
- Approvals: a run that stops with `awaiting_approval` just exits with code 2 here.

## Pitfalls

- Close both the tool router (stops the server subprocesses) and the store: add a `defer` right after each one is opened successfully.
- `toolrouter.NewStatic()` returns `(*Static, error)`; check the error even with no tools.
- Do not print anything to stdout except the summary — tests compare it exactly.
- `os.Executable()` in tests is the test binary; without `ADLC_RUN_AS_CLI=1` it would run the tests again instead of the fs server.
- `cobra` flag errors (missing `--task`) come back as plain errors → code 1 via the existing path.
- Relative `--root ./workspace` in the YAML is resolved against the agent file's directory because `ParsedToolServer.Dir` is that directory.
